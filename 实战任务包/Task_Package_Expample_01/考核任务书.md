# 江苏省职业院校技能大赛“人工智能应用”综合实战考核（练习示例01·数据方向）

## 项目：智慧城市共享单车运营分析
**考试时间：335分钟（约5.6小时）｜满分：100分**

### 一、项目背景
某城市公共服务管理部门拟建设一个AI辅助分析原型，需完成三项工作：共享单车小时需求预测、租赁日期分群，以及技术报告编制。使用一套公开真实数据完成运营预测分析。

### 二、数据与环境
- `data/bike_sharing/hour.csv`、`day.csv`：UCI 2011—2012年真实共享单车历史数据。
- Python、pandas、numpy、scikit-learn、matplotlib、seaborn。
- 统一设定随机种子`42`，保存软件版本与设备信息。原始文件须保持不变，全部处理结果存入`submission/`。

### 三、考核时间安排
| 阶段 | 时长 | 目标 |

| **合计** | **335分钟** | **约5.6小时** |

## 任务A1：真实租赁数据审计（20分）
1. 读取两份CSV，输出各自`shape`、字段名称、字段类型、`head()`、`describe()`结果。
2. 统计每列缺失值数量、完全重复行数量、`instant`或日期键重复情况，形成审计表。没有发现缺失或重复时，应将实际统计值记为0。
3. 对`cnt`、`temp`、`hum`、`windspeed`统计范围；至少对`cnt`使用IQR方法**识别并保存**异常候选行，并依据业务含义判断是否进行处理。
4. 验证`cnt == casual + registered`，说明将`casual`、`registered`加入`cnt`预测特征会产生什么问题；如实解释本数据中是否存在可直接识别个人的字段。
5. 形成`data_audit.md`、`data_profile.csv`、`outlier_candidates.csv`及用于后续任务的`hour_clean.csv`、`day_clean.csv`。

## 任务A2：共享单车小时需求回归预测（40分）
**预测目标**：使用历史环境与日期特征预测小时租赁总数`cnt`。
1. 建立特征表X和标签y；X不能包含`cnt`、`casual`、`registered`、`instant`；处理`dteday`，确保模型输入无原始字符串列或缺失值。
2. 按`train_test_split(test_size=0.2, random_state=42)`划分训练与测试。所有`StandardScaler`只在训练集拟合，禁止使用测试集的信息计算变换参数。
3. 训练`LinearRegression`、`Ridge`、`Lasso`三个模型；分别计算MAE、MSE、RMSE、R²，输出`regression_metrics.csv`和测试样本的`regression_predictions.csv`。
4. 对Ridge、Lasso比较至少4个不同`alpha`值，用训练集完成5折交叉验证；报告最优参数及平均CV分数，测试集不参与参数选择。
5. 绘制`regression_scatter.png`（真实值与预测值）及`regression_model_compare.png`（至少1个指标的模型对比），报告两个误差较大的样本并分析可能原因。
6. 用不超过200字说明：哪个模型更好？预测值与实际值产生偏差的原因是什么？根据模型评价指标和实验结果论证结论。

## 任务A3：KMeans运营日期分群（25分）
1. 以`day_clean.csv`为输入，至少使用`temp`、`hum`、`windspeed`、`cnt`四项数值建立日期聚类特征（可添加其他合理特征）。
2. 使用`StandardScaler`，计算`K=2~8`每个K的Inertia、Silhouette Score、Davies–Bouldin Index，保存为`kmeans_scores.csv`。
3. 绘制`elbow_curve.png`及一张二维聚类散点图（可选`temp`和`cnt`作为坐标轴，但须说明它只是二维投影），选择一个最终K并解释理由。
4. 输出含日期、聚类编号的`daily_clusters.csv`以及每个簇各特征均值、数量的`cluster_summary.csv`。
5. 根据结果用自然语言给每个簇命名，如“高需求温暖日”“低需求寒冷日”，名称必须有统计依据，而非事先硬编码。

## 任务C：综合技术报告（15分）
提交`reports/final_report.md`（不少于800字），至少包括：
- 项目背景、数据来源/授权注意事项、软件版本与设备；
- 总体流程图：数据获取→质量检查→处理/划分→训练→评价→输出；
- 3个回归模型指标对比及最佳模型选择依据；
- KMeans最终K、聚类类型及现实解释；
- **数据泄漏防范、局限性、改进方向**；
- 代码运行命令、运行环境与结果位置。
