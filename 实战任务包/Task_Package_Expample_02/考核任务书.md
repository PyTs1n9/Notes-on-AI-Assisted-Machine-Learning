# 江苏省职业院校技能大赛“人工智能应用”综合实战考核（练习示例02·数据方向）

## 项目：城市住房市场运营分析
**考试时间：335分钟（约5.6小时）｜满分：100分**

### 一、项目背景
某城市规划与住房研究部门拟建设一个AI辅助分析原型，需完成三项工作：区域住房价格预测、普查区域分群，以及技术报告编制。使用一套公开真实数据完成运营预测分析。

### 二、数据与环境
- `data/california_housing/housing.csv`：1990年美国加利福尼亚州人口普查真实住房数据。
- Python、pandas、numpy、scikit-learn、matplotlib、seaborn。
- 统一设定随机种子`42`，保存软件版本与设备信息。原始文件须保持不变，全部处理结果存入`submission/`。

### 三、考核时间安排

## 任务A1：真实住房数据审计（20分）
1. 读取CSV，输出`shape`、字段名称、字段类型、`head()`、`describe()`结果。
2. 统计每列缺失值数量、完全重复行数量、`longitude`与`latitude`组合重复情况，形成审计表。没有发现缺失或重复时，应将实际统计值记为0。
3. 对`median_house_value`、`population`、`total_rooms`、`median_income`统计范围；至少对`median_house_value`使用IQR方法**识别并保存**异常候选行，并依据业务含义判断是否进行处理；本数据存在房价封顶现象，须在审计报告中如实说明你的处理决定与理由。
4. 说明将标签`median_house_value`本身或由它直接衍生的列加入特征表X会产生什么问题；如实解释本数据中是否存在可直接识别个人的字段（提示：想想数据的统计单位是什么）。
5. 形成`data_audit.md`、`data_profile.csv`、`outlier_candidates.csv`及用于后续任务的`housing_clean.csv`。

## 任务A2：区域住房价格回归预测（40分）
**预测目标**：使用区域统计特征预测房价中位数`median_house_value`。
1. 建立特征表X和标签y；X不能包含`median_house_value`；处理`ocean_proximity`字符串类别列（转换为数值特征），确保模型输入无原始字符串列或缺失值。
2. 按`train_test_split(test_size=0.2, random_state=42)`划分训练与测试。所有`StandardScaler`只在训练集拟合，禁止使用测试集的信息计算变换参数。
3. 训练`LinearRegression`、`Ridge`、`Lasso`三个模型；分别计算MAE、MSE、RMSE、R²，输出`regression_metrics.csv`和测试样本的`regression_predictions.csv`。
4. 对Ridge、Lasso比较至少4个不同`alpha`值，用训练集完成5折交叉验证；报告最优参数及平均CV分数，测试集不参与参数选择。
5. 绘制`regression_scatter.png`（真实值与预测值）及`regression_model_compare.png`（至少1个指标的模型对比），报告两个误差较大的样本并分析可能原因。
6. 用不超过200字说明：哪个模型更好？预测值与实际值产生偏差的原因是什么？根据模型评价指标和实验结果论证结论。

## 任务A3：KMeans普查区域分群（25分）
1. 以`housing_clean.csv`为输入，至少使用`housing_median_age`、`total_rooms`、`population`、`median_income`、`median_house_value`五项数值建立区域聚类特征（可添加其他合理特征，也可自行衍生如每户房间数等新特征）。
2. 使用`StandardScaler`，计算`K=2~8`每个K的Inertia、Silhouette Score、Davies–Bouldin Index，保存为`kmeans_scores.csv`。
3. 绘制`elbow_curve.png`及一张二维聚类散点图（可选`median_income`和`median_house_value`作为坐标轴，但须说明它只是二维投影），选择一个最终K并解释理由。
4. 输出含区域标识（`longitude`、`latitude`）、聚类编号的`district_clusters.csv`以及每个簇各特征均值、数量的`cluster_summary.csv`。
5. 根据结果用自然语言给每个簇命名，如“高收入近海区”“低收入内陆区”，名称必须有统计依据，而非事先硬编码。
