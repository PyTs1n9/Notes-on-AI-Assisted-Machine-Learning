# 数据来源与字段说明

## A. California Housing（真实普查住房数据）
- 数据集原始出处：1990年美国加利福尼亚州人口普查数据（Pace & Barry, 1997），是机器学习教学最常用的真实公开数据之一。
- 配套书籍与下载仓库：《Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow》（Aurélien Géron）配套数据集：
  - 主源（GitHub）：https://raw.githubusercontent.com/ageron/handson-ml2/master/datasets/housing/housing.csv
  - 备用镜像（jsDelivr CDN，内容与主源一致）：https://cdn.jsdelivr.net/gh/ageron/handson-ml2@master/datasets/housing/housing.csv
- 来源：美国加州1990年普查区（census block group）级统计数据；用于回归/聚类分析教学，房价为1990年代美元价格，不代表当前房价。
- 原始文件：`data/california_housing/housing.csv`。
- 记录数：housing.csv **20,640行、10列**（不含表头）。

字段解释：

| 字段 | 含义 |
| --- | --- |
| `longitude` | 经度 |
| `latitude` | 纬度 |
| `housing_median_age` | 区域内房屋年龄中位数 |
| `total_rooms` | 区域内房间总数 |
| `total_bedrooms` | 区域内卧室总数（**本数据唯一含真实缺失值的列**，缺失数量以实际统计为准） |
| `population` | 区域内居住人口数 |
| `households` | 区域内家庭数 |
| `median_income` | 区域收入中位数（已缩放，数值≈收入/万美元） |
| `median_house_value` | 区域房价中位数（美元），**回归预测目标**；数据存在封顶值现象，须在审计中如实说明 |
| `ocean_proximity` | 距海位置类别（字符串，共5类），建模前需转换为数值特征 |

字段使用要求：`median_house_value`单独作为标签y，若将其本身或由它直接衍生的列放入特征X，属于**标签信息泄漏**。本数据以普查区为单位聚合统计，不存在可直接识别个人的字段。原始真实数据含真实缺失值与极端值；如实统计与说明即可，不允许捏造脏数据，也不允许忽略或删除真实缺失而不作记录。预测时需排除`median_house_value`（标签），`ocean_proximity`需要转换为可建模的数值特征。

**规范与数据使用注意事项：** 数据及元数据需注明来源；本数据来自公开教学数据集，使用条件以发布方信息为准；原始文件不得修改，所有处理结果另存到`submission/`。
