# 人工智能应用综合实战——任务包

考试时间：600分钟｜满分：100分

文件内容：
- `考核任务书.md`：项目要求、任务分值、考核结果与提交说明。
- `数据来源与字段说明.md`：两套公开真实数据的来源与原始结构。
- `数据准备.py`：下载原始数据，已下载的文件可跳过。
- `原始数据核验.py`：检查文件是否放置到指定目录。
- `提交目录说明.md`：程序、图表、指标、权重和报告的命名规范。
- `requirements.txt`：Python依赖列表；GPU相关PyTorch按本机环境安装。

运行顺序：
1. `python 数据准备.py`
2. `python 原始数据核验.py`
3. 按照 `考核任务书.md` 完成各项任务，结果存入 `submission/`。

无法联网时，按 `数据来源与字段说明.md` 中提供的来源提前下载并放入 `data/`。原始数据文件不作修改。公开数据许可条件以数据集发布方信息为准。
