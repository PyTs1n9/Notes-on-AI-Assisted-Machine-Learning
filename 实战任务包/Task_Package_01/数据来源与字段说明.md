# 数据来源与字段说明

## A. UCI Bike Sharing（真实共享单车租赁数据）
- 官方主页：https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset
- 官方压缩包：https://archive.ics.uci.edu/static/public/275/bike%2Bsharing%2Bdataset.zip
- 备用公开镜像（Udacity GitHub）：
  - hour.csv：https://raw.githubusercontent.com/udacity/deep-learning/master/first-neural-network/Bike-Sharing-Dataset/hour.csv
  - day.csv：https://raw.githubusercontent.com/udacity/deep-learning/master/first-neural-network/Bike-Sharing-Dataset/day.csv
- 来源：美国首都共享单车2011—2012年历史租赁与天气数据；用于回归/聚类分析，不代表当前交通状况。
- 原始文件：`data/bike_sharing/hour.csv`、`data/bike_sharing/day.csv`。
- 记录数：hour.csv **17,379行、17列**；day.csv **731行、16列**（不含表头）。

字段解释：

| 字段 | 含义 |
| --- | --- |
| `instant` | 记录ID（不可作为用于预测的有意义特征） |
| `dteday` | 日期 |
| `season` | 季节编码 |
| `yr` | 年份编码（0=2011，1=2012） |
| `mnth` | 月份 |
| `hr` | 小时（0～23；day.csv不包含） |
| `holiday`,`weekday`,`workingday` | 是否节假日、星期及工作日 |
| `weathersit` | 天气状况类别编码 |
| `temp`,`atemp`,`hum`,`windspeed` | 经过归一化处理的温度、体感温度、湿度、风速 |
| `casual`,`registered` | 临时用户与注册用户租赁数（与cnt直接构成目标值，**不可用于预测cnt**） |
| `cnt` | 租赁总数，回归预测目标 |

字段使用要求：`cnt=casual+registered`，若用casual或registered预测cnt，属于**标签信息泄漏**。原始真实数据可能没有缺失和重复；如实记录零值即可，不允许捏造脏数据。预测时需排除 `instant`, `casual`, `registered`, `cnt`（标签单独作为y），`dteday`需要转换为可解释的日期特征或仅保留用于划分。

## B. Ultralytics COCO128（真实照片+人工目标标注）
- 官方介绍：https://docs.ultralytics.com/zh/datasets/detect/coco128/
- 源码配置：https://github.com/ultralytics/ultralytics/blob/main/ultralytics/cfg/datasets/coco128.yaml
- 原始包：https://github.com/ultralytics/assets/releases/download/v0.0.0/coco128.zip
- 内容：COCO2017中抽取的128张实际拍摄图片及YOLO格式边界框。80个类别名称，部分类别在此子集未出现。
- 解压后默认应有 `data/coco128/images/train2017/` 与 `data/coco128/labels/train2017/`。

**数据划分要求：** 官方COCO128示例的`train`和`val`均指向相同128张图，只用于流程冒烟测试。本项目要求学生按图像文件名重新划分训练/验证集（建议80/20），同一张原图及其增强版本不得跨集合出现。

**二分类标签定义（ResNet18）：** 只根据原始YOLO标签文件判断图片中是否包含类别 `0=person`：有则归类 `has_person`，无则归类 `no_person`。二分类标签来自现有人工标注。仅用于验证分类训练流程，不保证模型具有生产环境的泛化能力。

**规范与数据使用注意事项：** 数据、元数据及预训练权重需注明来源；不能把COCO照片当成华盛顿共享单车站点的现场采集照片，两个模块的数据之间不存在真实一一对应关系。
