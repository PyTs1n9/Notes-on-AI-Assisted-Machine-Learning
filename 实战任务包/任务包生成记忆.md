## 一、这是什么
`Task_Package_Expample_01` 是对标母版 `实战任务包\Task_Package_01` 的**数据方向练习卷**：
- 只保留 **A1 数据审计 + A2 线性回归 + A3 聚类分析 + C 综合技术报告**；
- **不含任何深度学习内容**（删除母版 B1 图像核验、B2 ResNet18、B3 YOLOv8）；
- 面向学员当前水平（已学第一至十二课：回归线 + 聚类线；数据清洗为新增补课内容）。

## 三、必须逐字保留的规则（母版原文，不随删除变动）
1. A1/A2/A3 三个任务的任务条文与母版**逐字一致**（只允许改分值标题行）。
2. 固定随机种子 `42`；原始数据不得篡改；全部结果存入 `submission/`。
3. 不设置统一的模型准确率最低阈值；评分依据完成情况、计算过程、复现记录和评价解释。
4. `StandardScaler` 只在训练集拟合；测试集不参与参数选择。
5. 拓展题（不计入总分）：按日期分组拆分/严格时间顺序划分重测，解释与随机拆分差异。
6. 数据行数硬校验：hour.csv 17,379行17列；day.csv 731行16列。
7. 数据来源链接用 UCI 官方 + Udacity GitHub 镜像（见母版《数据来源与字段说明.md》A 部分）。

## 六、练习示例02（Task_Package_Expample_02，2026-10-28 新增）
同格式换数据集版：结构、分值（A1 20/A2 40/A3 25/C 15）、时长（335分钟）、文件清单、脚本风格与示例01 **完全一致**，仅数据集及其适配条文不同。

**数据集：California Housing（加州1990普查住房数据）**
- 下载：主源 `https://raw.githubusercontent.com/ageron/handson-ml2/master/datasets/housing/housing.csv`，备用镜像 `https://cdn.jsdelivr.net/gh/ageron/handson-ml2@master/datasets/housing/housing.csv`（本机网络 raw.githubusercontent 常被拒，镜像必留）
- 原始文件：`data/california_housing/housing.csv`；核验硬校验：**20,640行、10列**
- 实测事实（2026-10-28 pandas 实测，重新生成时应复测）：9个数值列全 float64 + `ocean_proximity` 字符串列（5类：<1H OCEAN 9136 / INLAND 6551 / NEAR OCEAN 2658 / NEAR BAY 2290 / ISLAND 5）；真实缺失仅 `total_bedrooms` **207**个；完全重复行 **0**；房价封顶值 500001 共 **965**条（A1 审计核心教学点）

**与示例01的条文适配（仅列数据集相关差异）：**
