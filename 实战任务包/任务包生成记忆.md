# 任务包生成记忆（Task_Package_Expample_01）

> ⚠️ 使用规则：本文件**仅在用户要求重新生成/修改实战任务包时**才阅读。平时开课、答疑、批改一律不读本文件。

## 一、这是什么
`Task_Package_Expample_01` 是对标母版 `实战任务包\Task_Package_01` 的**数据方向练习卷**：
- 只保留 **A1 数据审计 + A2 线性回归 + A3 聚类分析 + C 综合技术报告**；
- **不含任何深度学习内容**（删除母版 B1 图像核验、B2 ResNet18、B3 YOLOv8）；
- 面向学员当前水平（已学第一至十二课：回归线 + 聚类线；数据清洗为新增补课内容）。

## 三、必须逐字保留的规则（母版原文，不随删除变动）
1. A1/A2/A3 三个任务的任务条文与母版**逐字一致**（只允许改分值标题行）。
2. 固定随机种子 `42`；原始数据不得篡改；全部结果存入 `submission/`。
3. 不设置统一的模型准确率最低阈值；评分依据完成情况、计算过程、复现记录和评价解释。
4. `StandardScaler` 只在训练集拟合；测试集不参与参数选择。
5. 拓展题（不计入总分）：按日期分组拆分/严格时间顺序划分重测，解释与随机拆分差异。
6. 数据行数硬校验：hour.csv 17,379行17列；day.csv 731行16列。
7. 数据来源链接用 UCI 官方 + Udacity GitHub 镜像（见母版《数据来源与字段说明.md》A 部分）。
