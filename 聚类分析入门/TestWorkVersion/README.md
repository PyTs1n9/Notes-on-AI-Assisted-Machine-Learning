# 环境要求

Python 3.9+ ，安装四个包：
pip install numpy pandas scikit-learn matplotlib

四个包的作用：

numpy 数值计算，多维数组运算的底层

pandas 表格处理，去重/填充/分组统计

scikit-learn 标准化、KMeans、三大评估指标

matplotlib 画图（注意：它是 KMeans 之外唯一必须装的）

# ⚠ 关于 random_state

KMeans 的初始中心是随机选的，不固定随机种子的话， 你每次运行得到的簇编号、簇规模、SSE 都会
不一样，练习时无法对照答案。 本项目所有代码统一用 random_state=42，请你也不要改。
