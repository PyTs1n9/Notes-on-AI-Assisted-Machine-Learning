# 第一课：线性回归入门——让机器自己找出 y = w·x + b

## 【本节核心知识点】
线性回归就是"找一条最贴合数据点的直线"，用 sklearn 的 `LinearRegression` 的 `fit / predict / coef_ / intercept_` 完成「喂数据 → 学规律 → 做预测」的完整闭环。

## 【核心概念讲解】
想象你有一组数据：每天学习 1 小时考 10 分、2 小时考 13 分、3 小时考 16 分……人眼一看就知道"每多学 1 小时多 3 分，基础分 7 分"，也就是 `y = 3x + 7`。**线性回归干的就是这件事，只不过是由机器自动算出来。**

先解释几个马上要用到的术语（后面每节课都会用）：

| 术语 | 通俗解释 | 本课对应 |
|---|---|---|
| **特征（x）** | 用来做判断的"输入"，也叫自变量 | 学习时长 |
| **标签（y）** | 你想预测的"输出"，也叫因变量 | 考试成绩 |
| **样本（sample）** | 一行数据 = 一个观测对象 | 一个学生的一天 |
| **模型（model）** | 一套带参数的公式，这里是 y = w·x + b | LinearRegression 对象 |
| **拟合/训练（fit）** | 让模型从数据里算出最好的 w 和 b | model.fit(X, y) |
| **斜率 w / 截距 b** | w = x 每加 1，y 变多少；b = x 为 0 时 y 的值 | coef_ / intercept_ |

**机器的"学习"流程**：先瞎猜一条直线 → 看它和真实数据点差多远 → 不断调整 w、b 让差距最小 → 停在误差最小的那条线上。误差怎么量、怎么调，是后面几课的内容；今天先会用它。

## 【核心内置函数拆解】

### ① `np.array(列表)` — 把普通列表变成数组
- **作用**：sklearn 不收 Python 普通列表，必须先转成 numpy 数组（或表格）。
- **完整语法**：`np.array(object, dtype=None)`
- **关键参数**：`object` —— 列表、元组等；`dtype` —— 元素类型，一般不用管，自动推断。
- **返回值**：numpy 数组，如 `array([1, 2, 3])`。
- **常见坑**：元素类型不一致会被统一成一种（如 int+str 全变字符串），混着放会出怪结果。
- **适用场景**：任何要把"一组数"交给 numpy/sklearn 处理的时候。

### ② `数组.reshape(-1, 1)` — 把一列数变成"n 行 × 1 列"的表格
- **作用**：sklearn 的规矩：特征必须是**二维**（行 = 样本数，列 = 特征数）。一维数组它会直接报错。
- **完整语法**：`x.reshape(行数, 列数)`
- **关键参数**：`-1` 表示"这个维度我自己算"（元素总数 ÷ 另一维）；`1` 表示 1 列。
- **返回值**：变形后的新数组，`[1,2,3]` → `[[1],[2],[3]]`。
- **常见坑**：⚠️ 本课最大的坑。`x.reshape(3, 1)` 和 `x.reshape(1, 3)` 是两个东西；预测用的新数据也必须同样二维。
- **适用场景**：只有一个特征（单列 x）时，训练前必做这一步。

### ③ `LinearRegression()` — 创建线性回归模型
- **作用**：造一个"还没学习的模型"，它内部就装着待定的 w 和 b。
- **完整语法**：`LinearRegression(fit_intercept=True)`
- **关键参数**：`fit_intercept` —— 是否拟合截距 b，默认 `True`（要 b）；改成 `False` 就强制直线过原点。
- **返回值**：一个模型对象。
- **常见坑**：创建 ≠ 训练。这一步只是"领了个空模型"，`coef_` 此刻还不存在。
- **适用场景**：目标 y 是连续数值（分数、价格、温度）时的入门首选。

### ④ `model.fit(X, y)` — 训练（拟合）
- **作用**：把数据喂进去，机器自动算出误差最小的 w 和 b。
- **完整语法**：`model.fit(X, y, sample_weight=None)`
- **关键参数**：`X` —— 二维特征数组；`y` —— 一维标签数组；`sample_weight` —— 给某些样本加权重，入门用不到。
- **返回值**：模型对象本身（所以可以连写 `model.fit(X, y).predict(...)`）。
- **常见坑**：X 的行数必须等于 y 的长度，否则报错；X 必须二维（见②）。
- **适用场景**：有了一批"带答案的历史数据"，想让机器总结规律。

### ⑤ `model.predict(X_new)` — 预测
- **作用**：把新 x 代入学到的公式 y = w·x + b，算出预测值。
- **完整语法**：`model.predict(X)`
- **关键参数**：`X` —— 新特征，**列数必须和训练时一模一样**（本课都是 1 列）。
- **返回值**：一维数组，每个输入对应一个预测值。
- **常见坑**：没 `fit` 就 `predict` 会报错；给二维形状错了也报错（还是②那个坑）。
- **适用场景**：模型学好后，拿新数据要答案。

### ⑥ `model.coef_` / `model.intercept_` — 查看学到的参数
- **作用**：直接看机器找到的斜率 w 和截距 b。
- **返回值**：`coef_` 是**数组**（多个特征就多个 w），`intercept_` 是一个数。
- **常见坑**：⚠️ 带下划线结尾！sklearn 的约定：**结尾有 `_` 的是"训练后才有的属性"**，没训练就访问会报错。
- **适用场景**：想知道模型到底学到了什么规律、做讲解汇报时。

## 【完整代码示例 + 逐行注释】

```python
# ============ 线性回归第一课：让机器自己找出 y = w*x + b ============
import numpy as np                                     # numpy：Python 数值计算基础库，专门处理"数组"
from sklearn.linear_model import LinearRegression      # 从 sklearn 引入"线性回归"这个模型类

# 1) 准备数据：每天学习时长 x（特征），考试成绩 y（标签）
x_raw = np.array([1, 2, 3, 4, 5])      # 函数①：把普通列表变成"数组"
y = np.array([10, 13, 16, 19, 22])     # 成绩恰好满足 y = 3x + 7

# 2) 重塑形状：sklearn 要求特征必须是"二维表格"，这里只有 1 个特征 -> 每行 1 个数
X = x_raw.reshape(-1, 1)               # 函数②：转成 n行 x 1列；-1 表示"行数自动算"

# 3) 创建模型对象（此时它还什么都不会）
model = LinearRegression()             # 函数③：创建线性回归模型

# 4) 训练（拟合）：把数据喂给模型，让它找出最好的 w 和 b
model.fit(X, y)                        # 函数④：机器从数据里学规律

# 5) 查看学到的参数
print("斜率 w =", model.coef_)          # 函数⑥：学到的斜率 w（带下划线 = 训练后才有的属性）
print("截距 b =", model.intercept_)     # 函数⑥：学到的截距 b

# 6) 用学到的规律做预测
x_new = np.array([[6], [7]])           # 要预测的新数据，同样必须是二维（函数②的形状规矩）
y_pred = model.predict(x_new)          # 函数⑤：把新 x 代入公式算出预测值
print("学 6 小时 ->", y_pred[0], "分")
print("学 7 小时 ->", y_pred[1], "分")
```

**真实运行结果**（在项目环境 `.venv` 中实际运行）：

```
斜率 w = [3.]
截距 b = 6.9999999999999964
学 6 小时 -> 25.000000000000004 分
学 7 小时 -> 28.000000000000004 分
```

看到 `6.9999…` 而不是 `7.0` 别慌：这是计算机存小数的**浮点误差**，正常现象。机器精确找回了 w=3、b=7，预测 6 小时 25 分、7 小时 28 分——和公式算的一模一样。

## 补充答疑：特征为什么必须二维，标签为什么必须一维（2026-10-22 答疑补充）

### 一句话模型：一张表格 + 一列答案
- **特征 X = 输入的"表格"**：n 行 = n 个样本，d 列 = d 个特征，所以形状天然是 **(样本数, 特征数)**，即二维。1 个特征就是"只有 1 列的表格"，形状 (n, 1)。
- **标签 y = 答案清单**：每个样本只对应一个答案，n 个样本就是 n 个数排成一列，形状 **(样本数,)**，即一维。
- **两者的维度关系**：能对上的只有一根轴——**样本数**。必须满足 `X.shape[0] == y.shape[0] == n`；X 多出来的第 2 维（特征数）在 y 那边不存在，因为答案不需要"列"。

```
X (5, 1)   =  5 个样本，1 个特征        y (5,)     =  5 个答案
┌───┐                                    ┌────┐
│ 1 │  ← 一个样本占一行                    │ 10 │
│ 2 │                                    │ 13 │
│ 3 │     样本数 5 必须两边相等  ←────────→ │ 16 │
│ 4 │                                    │ 19 │
│ 5 │                                    │ 22 │
└───┘                                    └────┘
```

### 为什么 X 必须二维？
sklearn 所有模型共用一条统一规矩：`X.shape == (样本数, 特征数)`。哪怕只有 1 个特征也得写成 (n, 1) 的表格。好处是：今天 1 个特征、明天 100 个特征，代码一行都不用改。`reshape(-1, 1)` 的两个参数正好对应这根轴：`-1` = 样本数让它自己算（不许变），`1` = 特征数补上（表格必须有列数）。

### 为什么 y 必须一维？
y 不是表格，是"每行 X 对应一个答案"的清单。如果把 y 送成二维 (n, 1)，`LinearRegression` 不会报错，而是当成"1 个目标的多输出"照单全收——实测 `coef_` 形状从 `(1,)` 变成 `(1, 1)`，`predict` 返回值也从一维变二维，后面接评价指标、画图时就会冒出一堆想不通的形状错误。**不报错的坑比报错的坑更危险**，所以规矩定为：y 一维。

### 真实报错对照（.venv 实测）
| 错误操作 | 实际报错 |
|---|---|
| X 给成一维 | `Expected 2D array, got 1D array instead`（官方提示就是让你 `reshape(-1, 1)`） |
| y 给成二维 (n,1) | 不报错！静默变多输出，`predict` 形状变 (1,1) —— 隐性坑 |
| X、y 样本数不一致 | `Found input variables with inconsistent numbers of samples: [5, 4]` |
| 预测时特征数和训练不一致 | `X has 2 features, but LinearRegression is expecting 1 features as input` |

### 我的疑问
x_new = np.array([[7]]) 这里用刀2个括号，np.array()是函数，里面第一层括号是列表，内层的括号是什么意思

#### 老师答疑
（小笔误：是"用到"2个括号）展开 `np.array([[7]])` 一共三层括号，各管各的：
1. `np.array( ... )` 最外层**圆括号** = 函数调用的括号，每个函数都有，和数据形状无关；
2. `[[7]]` 的**外层方括号** = 一个列表，装的是"行"（每个样本一行）；
3. 里层 `[7]` = 具体某一行，装这一个样本的所有特征（这里只有 1 个特征）。

**记忆口诀：几层方括号就是几维。**
- `[7]` → 1 层 → 一维 (1,) → ❌ sklearn 不收
- `[[7]]` → 2 层 → 二维 (1, 1) = 1 个样本 × 1 个特征 → ✅
- `[[6], [7]]` → 2 层 → 二维 (2, 1) = 2 个样本 × 1 个特征 → ✅（第一课示例里同时预测 6、7 小时就是这么写的）

所以内层括号的含义是"一行的边界"：把每个样本的特征关进自己的小列表，一行一个样本。

## 【本节重点总结】
1. 线性回归 = 机器自动找出最贴合数据的直线 y = w·x + b，w 是斜率、b 是截距。
2. 标准四步：`np.array` 造数据 → `reshape(-1,1)` 变二维 → `fit` 训练 → `predict` 预测。
3. 两个必记的坑：特征必须二维；`coef_`/`intercept_` 带下划线，训练后才有。
