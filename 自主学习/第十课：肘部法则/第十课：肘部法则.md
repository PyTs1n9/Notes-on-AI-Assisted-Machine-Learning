# 第十课：肘部法则

## 【本节核心知识点】

K 分几簇不靠拍脑袋：把 K = 2~10 各跑一遍 KMeans，把每个 K 的 `inertia_`（簇内平方和）连成折线，**下降由陡变缓的"拐弯处"（肘部）就是该选的 K**。

## 【核心概念讲解】

### 1. 第九课留下的悬念：k 到底定几？

第九课我们人工拍板 `n_clusters=3`，当时就说了："分几簇是人定的，怎么科学地选是后两课的活"。今天解决它。

### 2. inertia_ 重新认识——它是"平方和"，不是"平均距离"

先把第九课的 `inertia_` 定义钉死（很多人会记成"平均距离"，**错**）：

> `inertia_` = 簇内每个样本到**本簇中心**的距离**平方**，全部加起来（簇内平方和，SSE）。它**没有除以样本数**——不是平均。

由定义直接推出两条性质，是今天一切的地基：

1. **簇越紧凑，它越小**（组员都贴着队长，距离平方和自然小）；
2. **K 越大，它越小**——把 100 个人分成 100 簇，每人都自成一簇、中心就是自己，`inertia_` 直接等于 0。所以 **K 越大 `inertia_` 越小是必然规律，不能挑"最小的那个 K"**，不然答案永远是 K 的上限，毫无意义。

### 3. 下降幅度（边际收益递减，diminishing returns）——真正的信号藏在这里

既然不能挑最小的，那就看**每多分一簇，`inertia_` 能少多少**——"下降幅度"：

- 数据里**真有几坨结构**时：前几档大刀阔斧地降（把混在一起的两坨拆开，紧凑度暴涨）；
- **分够之后**：再加簇只是把本来就很紧凑的一坨切碎，下降幅度骤减（收益递减）。

"由陡变缓"的那道分界线，就是数据里"天然有几坨"的证据。

### 4. 肘部法则（elbow method，肘部法则）——把信号画成曲线

把 K 横着放、`inertia_` 竖着画，连成折线：曲线先陡降、后趋平，**拐弯处形状像手臂的肘关节**，所以叫"肘部"。肘部对应的 K 就是推荐值。

图 + 表配合读：图看"拐弯"，表看"下降幅度"的具体数字，两边互相印证（现实数据的肘部常是圆弯，光看图容易看歪，数字不会骗人）。

### 5. 肘部不清晰怎么办

有些数据的曲线是慢慢变平的圆弧，没有明显的肘——这很正常。下一课的**轮廓系数**会从"簇内像、簇间不像"的角度给出第二个证据，两个方法互相印证着定 K。

### 6. 今天的工作流程

`StandardScaler` 标准化（第九课原样）→ `for k in range(2, 11)` 循环训练 KMeans → 收集每个 K 的 `inertia_` 和下降幅度 → `plt.plot` 画曲线 → 读肘部。

## 【核心内置函数拆解】

### ① `range(2, 11)` — 生成一串整数（本课的 K 候选序列）

- **作用**：生成"从起点到终点前一个"的整数序列，最常用来驱动 `for` 循环。
- **完整语法**：`range(stop)`（从 0 到 stop-1）、`range(start, stop)`（从 start 到 stop-1）、`range(start, stop, step)`（再加步长）。本课用 `range(2, 11)`。
- **关键参数**：`start` 起点（**含**）、`stop` 终点（**不含**！）、`step` 步长（默认 1）。
- **返回值**：一个 **range 对象**，不是列表——直接打印只显示 `range(2, 11)` 字样；想看到数字要 `list(range(2, 11))`。
- **常见坑**：终点不含！`range(2, 11)` 才是 2~10（9 个数），写成 `range(2, 10)` 会悄悄丢掉 K=10。
- **适用场景**：循环试不同参数（本课试 K）、生成下标。

### ② `plt.plot(x, y, 'o-')` — 画折线图

- **作用**：把 (x, y) 数据点连成折线，看两列数值的趋势关系。肘部曲线就是"K 值 ~ inertia"的折线。
- **完整语法**：`plt.plot(x, y, 样式字符串, label='图例文字')`；样式串 `'o-'` = 圆点 + 实线（`'s--'` = 方块 + 虚线，第五课用过）。
- **关键参数**：`x` 横轴数据（本课 K 值列表）、`y` 纵轴数据（本课 inertia 列表）、样式字符串、`label`（图例，配 `plt.legend()` 用）。
- **返回值**：无（图直接画在"当前图"上）。
- **常见坑**：
  - **只传一维 `y` 不传 `x` 时，横轴默认是下标 0, 1, 2, …**（第五课的老坑）——本课必须显式传 K 值当 x；
  - `x` 和 `y` 长度必须一样，不然直接报错；
  - 图里想显示中文，先设字体两行（见下方代码里的 `rcParams`），否则中文变方框（tofu）。
- **适用场景**：一个量随另一个量变化的趋势（指标随参数变、分数随 epoch 变……）。

### ③ `plt.xlabel()` / `plt.ylabel()` / `plt.title()` / `plt.savefig()` — 图的标签三件套 + 存图

- **作用**：给 x 轴、y 轴贴名字，给图起标题，最后把图存成图片文件。没有它们，图能画出来但没人看得懂。
- **完整语法**：`plt.xlabel('x 轴文字')`、`plt.ylabel('y 轴文字')`、`plt.title('图标题')`、`plt.savefig('文件名.png', dpi=120)`。
- **关键参数**：`savefig` 的 `dpi` 是清晰度（120 够用，越大文件越大）；文件名后缀 `.png`。
- **返回值**：无。
- **常见坑**：`savefig` 要在 `plt.show()` **之前**（否则存到一张空白图；本课用 `Agg` 后端只存图不弹窗，没这个烦恼）；标签文字写完配一行 `plt.tight_layout()`，防止标签被裁掉。
- **适用场景**：任何要出图交差的场合——作业、报告、课件。

### ④ `列表.append(值)` — 往列表末尾追加一个值

- **作用**：把循环里算出的一个个结果收集成一个列表（本课收集各 K 的 `inertia_`）。
- **完整语法**：`列表.append(值)`。列表要先存在（`空列表 = []` 初始化）。
- **关键参数**：一个值——数字、字符串、什么都行。
- **返回值**：**`None`！** 它直接改原列表，不返回新列表。写成 `x = 列表.append(1)` 会得到 `None`——这是它最大的坑。
- **常见坑**：见上（返回 None）；要新列表不改原列表用 `列表 + [值]` 或 `列表.copy()` 后再操作。
- **适用场景**：循环收集结果，攒成一列再画图或打印。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第十课演示：肘部法则给顾客数据选 K ============
import numpy as np                                          # 数值计算库
import pandas as pd                                         # 表格处理库
from sklearn.preprocessing import StandardScaler            # 标准化工具
from sklearn.cluster import KMeans                          # KMeans 聚类算法
import matplotlib                                           # 画图库本体
matplotlib.use('Agg')                                       # 无界面环境也能画图（只存文件不弹窗）
import matplotlib.pyplot as plt                             # 画图工具
plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei']  # 中文字体，防止中文变方框
plt.rcParams['axes.unicode_minus'] = False                  # 负号正常显示

# ---------- 1. 读数据 + 标准化（第九课的流程原样搬来） ----------
df = pd.read_csv('customers.csv', encoding='utf-8-sig')     # 读第九课那份顾客数据（60 行 2 列）
scaler = StandardScaler()                                  # 创建标准化器
X_scaled = scaler.fit_transform(df)                        # 标准化：拉回均值 0、标准差 1

# ---------- 2. 循环 K=2~10，收集每个 K 的 inertia_ 和下降幅度 ----------
Ks = list(range(2, 11))                # 函数①：range 生成 2~10 共 9 个整数，转成列表
inertias = []                          # 空列表，装每个 K 的 inertia_（函数④往里追加）
drops = []                             # 空列表，装"比上一档少了多少"
prev = None                            # 记住上一档的 inertia_
for k in Ks:                           # 依次取 2, 3, 4, ..., 10
    km = KMeans(n_clusters=k, random_state=42, n_init=10)  # 每档一个聚类器（参数照旧钉死）
    km.fit(X_scaled)                                      # 聚类（喂的只有特征，没有标签）
    inertias.append(round(km.inertia_, 2))                # 函数④：append 收集本档 inertia_
    if prev is None:                                      # K=2 是第一档，没有"上一档"
        drops.append(None)                                # 用 None 占位
    else:                                                 # 其余各档
        drops.append(round(prev - km.inertia_, 2))        # 下降幅度 = 上一档 - 本档
    prev = km.inertia_                                    # 把本档记成"上一档"

# ---------- 3. 打印 "K ~ inertia ~ 下降幅度" 对照表 ----------
for k, iner, drop in zip(Ks, inertias, drops):             # 三列并排走（zip 把三个列表对齐）
    d = '—' if drop is None else drop                      # 第一档没有下降幅度，画个横杠
    print(f'K={k:<3d} inertia_={iner:<6} 下降幅度={d}')

# ---------- 4. 画肘部曲线 ----------
plt.plot(Ks, inertias, 'o-')                               # 函数②：plt.plot 画折线（x=K值，y=inertia）
plt.xlabel('簇数 K')                                        # 函数③：x 轴标签
plt.ylabel('inertia（簇内平方和）')                          # 函数③：y 轴标签
plt.title('肘部法则：K 与 inertia 的关系（顾客数据）')         # 函数③：图标题
plt.tight_layout()                                          # 自动收紧边距，防止标签被裁掉
plt.savefig('顾客数据-肘部曲线.png', dpi=120)                 # 函数③：存成图片（dpi=清晰度）
print('图片已保存：顾客数据-肘部曲线.png')

# ---------- 5. 读结果 ----------
print(f'读结果：K=2→3 下降幅度 {drops[1]}，K=3→4 只剩 {drops[2]}，4 之后每档都不足 1——')
print('下降从 K=3 起明显变缓，肘部在 K=3，正好印证第九课人工定的 K=3。')
```

读结果的三个着眼点：

1. **`inertia_` 一路减小是必然**：42.81 → 6.71 → … → 1.88，K 越大越小——所以盯着"最小"没意义，要盯**下降幅度**。
2. **下降幅度的断崖**：K=2→3 少了 36.11，K=3→4 只剩 1.39，之后每档都不足 1——"由陡变缓"的拐弯在 K=3。
3. **图和表互相印证**：曲线在 K=3 处拐出"肘部"，和下降幅度的断崖位置一致；K=3 也正好是第九课人工选定的簇数。
