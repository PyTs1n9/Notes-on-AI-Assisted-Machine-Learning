# 第四课：Pandas 取数——loc、iloc、条件筛选与 CSV 读写

## 【本节核心知识点】
从表格里取数据有三种问法：按**列名**取一列（`df['列名']`）、按**名字/位置**取任意块（`df.loc` / `df.iloc`）、按**条件**挑行（`df[布尔条件]`）；再用 `to_csv` / `read_csv` 把表格存进文件、读回内存，数据处理的"进"和"出"就齐了。

## 【核心概念讲解】

### 取数的三种问法
拿到一张表，你要数据时心里的问法无非三种，Pandas 每种都给了对应写法：

| 你的问法 | 用什么 | 例子 |
|---|---|---|
| "把**数学**这一列给我" | `df['数学']` | 按列名取一列 |
| "**小红**这个人 / **前 3 行**的英语成绩" | `df.loc` / `df.iloc` | 按名字、按位置取 |
| "数学 **85 分以上**的都有谁" | `df[df['数学'] >= 85]` | 按条件挑行 |

**loc 和 iloc 的本质区别**（本课最大的一对概念）：
- `loc` = **按名字**取（location 的缩写）：行名、列名；
- `iloc` = **按位置**取（integer location 的缩写）：第几行、第几列，**从 0 开始数**。
- 我们的示例表把行名设成 `a~e`，就是为了让两者一眼分清：`loc['b']` 和 `iloc[1]` 取到的都是小红，但一个用名字、一个用位置。

先解释马上要用的术语：

| 术语 | 通俗解释 | 例子 |
|---|---|---|
| **切片（slice）** | 一次取"连续的一段" | 前 3 行、数学和英语两列 |
| **布尔条件** | 每行算出 True/False 的判断式 | `df['数学'] >= 85` 对每行回答"是/否" |
| **CSV 文件** | 一种"纯文本表格"，逗号分隔，Excel 能直接打开 | `成绩单.csv` |
| **编码（encoding）** | 文字在文件里怎么存的"密码表"，对不上就乱码 | UTF-8、GBK |
| **BOM** | 文件开头藏的一个"这是 UTF-8"标记，Excel 靠它识别中文 | `utf-8-sig` 编码自带 |

**为什么要学读 CSV**：真实项目的数据几乎都来自文件（CSV/Excel）。后面两个综合训练课题里的"数据读取"就是 `pd.read_csv`，今天先把管道打通。

## 【核心内置函数拆解】

### ① `df['列名']` — 取一列
- **作用**：按列名取出一列数据。
- **完整语法**：`df['列名']`；取多列用双层括号 `df[['列1', '列2']]`。
- **关键参数**：列名（字符串，加引号）。
- **返回值**：单括号 → **Series**（一列）；双括号 → **DataFrame**（还是表）。
- **常见坑**：⚠️ 单括号和双括号返回的东西**类型不同**——`df['数学']` 是 Series，`df[['数学']]` 是只有一列的 DataFrame，写错后面用起来会别扭。另外 `df.数学` 这种"点号写法"在列名是中文或带空格时不保险，**统一写 `df['数学']`**。
- **适用场景**：只想看或算某一列时。

### ② `df.loc[行, 列]` — 按"名字"取
- **作用**：用行名、列名取任意一块数据，行和列都能挑。
- **完整语法**：`df.loc[行名或行切片或条件, 列名或列名列表]`（只写行、省略列 = 取整行）。
- **关键参数**：
  - 行：单个行名 `df.loc['b']`；名字切片 `df.loc['a':'c']`；布尔条件 `df.loc[df['数学'] >= 85]`；
  - 列：单个列名或列表 `['姓名', '数学']`。
- **返回值**：单行或单列 → Series；切片/多列 → DataFrame；行、列都只指定一个 → 一个具体值。
- **常见坑**：⚠️ **名字切片两端都包含**！`df.loc['a':'c']` 是 a、b、c **三行**——和 Python 列表切片"不含末尾"的规矩**相反**，这是本课最大的坑。
- **适用场景**：知道行名列名时的首选取数方式。

### ③ `df.iloc[行号, 列号]` — 按"位置"取
- **作用**：用"第几行、第几列"取数，都**从 0 开始数**。
- **完整语法**：`df.iloc[行号或行切片, 列号或列切片]`。
- **关键参数**：全是数字：`df.iloc[1]` = 第 1 行（其实是第 2 行，因为从 0 数）；`df.iloc[0:2, 1:3]` = 行 0~1、列 1~2。
- **返回值**：同 loc——单行/单列 → Series；切片 → DataFrame；行列各一个 → 一个具体值。
- **常见坑**：⚠️ 位置切片**不含末尾**（和 Python 列表一致）——`iloc[0:2]` 只有 2 行。还有：iloc 里**写名字会报错**，它只认数字。
- **适用场景**：按"第几个"取数时，比如"最后 3 行"（`df.iloc[-3:]`）。

### ④ `df[布尔条件]` — 按条件挑行
- **作用**：把符合条件的行整行挑出来，像 Excel 的筛选器。
- **完整语法**：`df[条件]`，条件一般是"列与值比较"，如 `df['数学'] >= 85`。
- **关键参数**：条件怎么算：比较运算符 `>` `<` `>=` `<=` `==`（等于双等号）`!=`（不等），对每行算出 True/False，留下 True 的行。
- **返回值**：DataFrame（只含满足条件的行）。
- **常见坑**：⚠️ 组合多个条件时用 `&`（且）、`|`（或）、`~`（非），而且**每个条件必须各自加括号**：`df[(df['数学'] >= 85) & (df['英语'] >= 80)]`。写 `and` / `or` 会直接报错。
- **适用场景**：筛选记录，"找出……的人/商品/样本"。

### ⑤ `pd.read_csv(路径)` — 把 CSV 文件读成表格
- **作用**：把磁盘上的 CSV 文件读进内存变成 DataFrame，数据处理的"入口"。
- **完整语法**：`pd.read_csv(filepath_or_buffer, encoding=None, sep=',')`（后两个最常用，其余参数入门不碰）。
- **关键参数**：
  - `filepath_or_buffer`：文件路径。相对路径是相对"**运行代码时所在的目录**"，不是相对代码文件；
  - `encoding`：编码，读中文数据常用 `'utf-8-sig'` 或 `'gbk'`；
  - `sep`：分隔符，默认逗号。
- **返回值**：DataFrame。
- **常见坑**：
  1. 路径写错报 `FileNotFoundError`——先确认文件在哪、代码从哪个目录跑；
  2. ⚠️ 打开是乱码 = 编码不对，换 `encoding='gbk'` 再试；
  3. Excel 另存的"CSV"可能是分号分隔、GBK 编码，读进来列名变成一整列时先检查 `sep` 和 `encoding`。
- **适用场景**：任何"从文件拿数据"的场合，是实战第一入口。

### ⑥ `df.to_csv(路径)` — 把表格存成 CSV 文件
- **作用**：把 DataFrame 写到磁盘，数据处理的"出口"（和⑤是一对）。
- **完整语法**：`df.to_csv(path, index=True, encoding=None)`
- **关键参数**：`path` —— 存到哪；`index` —— 是否把行号也存进去；`encoding` —— 同⑤。
- **返回值**：什么都不返回（文件写到磁盘）。
- **常见坑**：⚠️ `index` 默认是 `True`，会把行号多存一列，下次 `read_csv` 读回来就多一列 `Unnamed: 0`——**一般都写 `index=False`**。存的 CSV 想用 Excel 打开不乱码，用 `encoding='utf-8-sig'`。
- **适用场景**：保存处理好的数据、和 Excel 交换数据。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第四课：Pandas 取数——loc / iloc / 条件筛选 + CSV 读写 ============
import pandas as pd                                    # 表格库（惯例缩写 pd）

# ---- 0) 准备表格：5 个学生三科成绩（自定义行名 a~e，让 loc 和 iloc 的区别看得清）----
df = pd.DataFrame({
    '姓名': ['小明', '小红', '小刚', '小丽', '小强'],
    '数学': [90, 85, 78, 92, 88],
    '英语': [76, 92, 80, 85, 79],
    'Python': [88, 95, 70, 90, 82],
}, index=['a', 'b', 'c', 'd', 'e'])                    # index：自定义行名
print(df)

# ---- 1) 取一列 ----
print(df['姓名'])                                       # 函数①：按列名取一列，返回 Series
print("取一列的类型:", type(df['姓名']))                   # 确认返回的是 Series

# ---- 2) loc：按"名字"取 ----
print(df.loc['b'])                                      # 函数②：行名 b 的整行
print(df.loc['a':'c', '数学':'英语'])                     # 函数②：名字切片——⚠️ 两端都包含！
print(df.loc[df['数学'] >= 85, ['姓名', '数学']])         # 函数②+④：数学>=85 的人，只要姓名和数学两列

# ---- 3) iloc：按"位置"取（从 0 数）----
print(df.iloc[1])                                       # 函数③：第 1 行 = 第 2 个人（小红）
print(df.iloc[0:2, 1:3])                                # 函数③：位置切片——⚠️ 不含末尾（Python 规矩）
print(df.iloc[3, 2])                                    # 函数③：第 3 行第 2 列的那一个数

# ---- 4) 布尔条件筛选行 ----
print(df[df['Python'] >= 85])                           # 函数④：Python>=85 的所有行
print(df[(df['数学'] >= 85) & (df['英语'] >= 80)])        # 函数④：组合条件——用 &（且），每个条件加括号

# ---- 5) 存 / 读 CSV ----
df.to_csv('成绩单.csv', index=False, encoding='utf-8-sig')   # 函数⑥：存成 CSV（不存行号，中文不乱码）
df2 = pd.read_csv('成绩单.csv', encoding='utf-8-sig')   # 函数⑤：把 CSV 文件读回成 DataFrame
print(df2)                                              # 内容和原表一样（行名变回自动编号）
print("读回来的形状:", df2.shape)
```

## 【补充答疑】`df.loc[条件, 列名列表]` 怎么拆着读

**疑问**：`print(df.loc[df['math'] >= 85, ['name', 'math']])` 这一整块看不懂——方括号里塞了两样东西，各自是什么？

**拆解**：`loc` 的方括号永远是 `loc[行, 列]` 两段，**逗号前管"留哪些行"，逗号后管"留哪些列"**。把这行拆成三步看（真实运行过的中间结果）：

1. `df['math'] >= 85` → 一串 True/False（**行的开关**，每行一个）：

```
0     True    ← 90 >= 85
1     True    ← 85 >= 85
2    False    ← 78 < 85
3     True    ← 92 >= 85
4     True    ← 88 >= 85
Name: math, dtype: bool
```

2. `df.loc[开关]` → 留下开关是 True 的行（第 0、1、3、4 行，丢掉第 2 行小刚）；
3. 再补上 `['name', 'math']` → 这些行里**只保留 name、math 两列**（english 列被丢掉）。

**顺序是固定的**：逗号前**永远是行**、逗号后**永远是列**，不能颠倒。第一个位置变的只是"挑行的写法"——可以是单个行名 `df.loc['b']`、名字切片 `df.loc['a':'c']`、布尔条件 `df.loc[df['数学'] >= 85]`、行名列表 `df.loc[['a','c']]`，但挑的都是**行**。把列名写进第一个位置会报 `KeyError`（它当成行名去找，找不到）。

**只想挑列、不挑行**怎么办？行的位置写 `:`（表示"所有行"）：

```python
df.loc[:, ['name', 'math']]   # 所有行，只要 name、math 两列
```

**别和 `df[...]` 搞混**——那是另一个规矩：单层括号里只放一样东西，放**列名**就是取列（`df['name']`），放**布尔条件**就是挑行（`df[df['math'] >= 85]`）。"一个括号里可能是列也可能是行"说的是 `df[...]`，而 `loc[行, 列]` 两段各管各的、顺序固定。

## 【补充答疑】`df.loc['m3']` 和 index 是什么关系

**疑问**：`print(df.loc['m3'])` 取的是"index 内的数据"吗？index 到底扮演什么角色？

**答疑**：`loc` 就是**拿 index（行名）当查找钥匙**的取数方式——`'m3'` 存放在 index 里，`df.loc['m3']` 的意思是"到 index 里找到叫 `m3` 的那一行，把它取出来"。分三点说清：

1. **index 不是数据列**：它是一串行名。`df.index` 可以查看，`list(df.index)` 能取出所有行名（`['m1', 'm2', 'm3', 'm4', 'm5']`），打印表格时它显示在最左边一列位置，但**不算表里的数据**；
2. **取出来的是数据、不是 index**：`df.loc['m3']` 返回 **Series**，里面是该行**各列的值**（电影名、票房、评分、上映天数）；`m3` 只是这一行的"名牌"，出现在结果末尾的 `Name: m3` 处。真实输出：

```
电影名     孤注一掷
票房      3849
评分       9.1
上映天数      75
Name: m3, dtype: object
```

3. **练习要求只打印"电影名"和"票房"两个值** → 用两段式 `df.loc['m3', ['电影名', '票房']]`；只要一个值就 `df.loc['m3', '票房']`（返回一个具体数）。对照记忆：`df.iloc[2]` 是"按位置取第 3 个"，`df.loc['m3']` 是"按名字取叫 m3 的"——练习特意用 m1~m5 当行名，就是为了让这两个"第三个"区分开。

## 【补充答疑】存 CSV 和读 CSV 必须"成对"（2026-10-24 单元测试补充）

**疑问**：单元测试题目 2 里，存的时候写了 `to_csv(index=False)`，读回来却加了 `read_csv(index_col=0)`，结果形状是 `(5, 2)`、不是手算的 `(5, 3)`。

**规矩一句话**：`to_csv` 的 `index` 和 `read_csv` 的 `index_col` 是**一对搭档，必须成对**：
- `to_csv(index=True)`（行名写进文件）↔ `read_csv(..., index_col=0)`（把第 0 列吃回行名）；
- `to_csv(index=False)`（行名不写进文件）↔ `read_csv` **不加** `index_col`。

**拆开看错在哪**：存的是 `index=False` → 文件里只有"姓名/数学/英语"三列、没有行名列。这时 `read_csv('单测1.csv', index_col=0)` 会把**第一列"姓名"当成行名**吃掉 → 表里只剩"数学/英语"两列 → `shape = (5, 2)`。两种读法实跑对照（`.venv`）：

```text
不加 index_col  -> (5, 3) | 列名: ['姓名', '数学', '英语']   ← 和存的写法成对，正确
加 index_col=0 -> (5, 2) | 索引: ['甲', '乙', '丙', '丁', '戊']  ← 姓名列被当行名吃掉
```

**和纠错题 3 对照记**：那题是"`index=True` 存、漏配 `index_col=0`"（行名归位失败，`loc['m3']` 报 KeyError）；这次是反方向——"`index=False` 存、多配了 `index_col=0`"（数据列被吃掉）。两个坑共用一条规矩：**存读成对**。

### 我的疑问
```
df = pd.read_csv('票房.csv', index_col=0)
```

我如果不写index_col=0，就read_csv出来的数据就行号列就变成0 1 2 3 4,

#### 老师答疑

**你的疑问**：不写 `index_col=0`，`read_csv` 读回来的数据行号就变成 0 1 2 3 4，为什么？

**答疑**：`index_col=0` 的意思是告诉 `read_csv`："**第 0 列不是数据，把它用作行名**"。不写它，`read_csv` 只能把 CSV 的第一列（m1~m5）当成一个普通数据列读进来，同时给每行自动编新行号 0~4。实跑对照（真实输出）：

```
  Unnamed: 0    电影名   票房    评分  上映天数
0         m1  film1  100   8.8     5
1         m2  film2   30   9.2     3
2         m3  film3  200   6.7     2
3         m4  film4   50   7.9     1
4         m5  film5   40  10.0     8
形状: (5, 5)
df3.loc["m3"] 报错 KeyError: 'm3'
```

不写 `index_col=0` 的三个后果：① m1~m5 掉进数据区、变成一列（自动起名 `Unnamed: 0`）；② 形状从 (5, 4) 变成 (5, 5)；③ 行名没了，`df.loc['m3']` 直接报 KeyError——第 4 问就没法做了。

**两种存/读是配套的**（记住"怎么存、就怎么读"）：

| 存 | 读 | 结果 |
|---|---|---|
| `to_csv(index=False)` | `read_csv(...)` | 行名不存，读回行号自动 0~4（练习原方案） |
| `to_csv(index=True)`（默认） | `read_csv(..., index_col=0)` | 行名存进第 0 列，读回时放回行名位置（你的方案） |

一句话：**`index=True` 存 ↔ `index_col=0` 读，两个参数是一对**。你观察到的现象和你的直觉完全正确。

## 【本节重点总结】

1. 取数三问法：按列名 `df['列']`、按名字/位置 `loc`/`iloc`、按条件 `df[布尔条件]`；loc 和 iloc 的区别是"名字 vs 位置"。
2. 记死两个相反的切片规矩：`loc` 名字切片**两端都包含**，`iloc` 位置切片**不含末尾**；组合条件用 `&`/`|` 且每个条件加括号。
3. 数据的进和出：`pd.read_csv` 读文件、`df.to_csv` 存文件，配对使用；记住 `index=False` 和 `encoding='utf-8-sig'` 两个常用参数防坑。
