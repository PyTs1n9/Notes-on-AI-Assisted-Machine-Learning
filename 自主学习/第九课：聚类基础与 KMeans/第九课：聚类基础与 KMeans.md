# 第九课：聚类基础与 KMeans

## 【本节核心知识点】

数据没有标签（label）也能分组：先用 `StandardScaler` 把特征拉回同一量纲（单位），再用 `KMeans` 把样本分成 k 个簇（cluster），最后读它的三个属性 `labels_`、`cluster_centers_`、`inertia_`。

## 【核心概念讲解】

### 1. 无监督学习（unsupervised learning，无监督学习）——没有标准答案的学习

前八课全是**监督学习（supervised learning）**：数据里有标签 y（考试成绩、销售额），模型学"特征 → 标准答案"的规律，学完能对答案。

**无监督学习**反过来：数据里**没有标签**，只有特征。目标不是"预测答案"，而是"发现结构"——让数据自己"物以类聚"。分完组后，每组叫什么名字由人来起。

一句话对比：

| | 监督学习（前八课） | 无监督学习（本课起） |
|---|---|---|
| 有没有标签 y | 有 | **没有** |
| 干什么 | 学规律、做预测 | 找结构、做分组 |
| 例子 | 预测考试成绩 | 顾客自动分成几群 |

### 2. 样本、特征——老朋友重新定位

- **样本（sample）**：表里的一行，一个具体对象（一位顾客）。
- **特征（feature）**：表里的一列，描述对象的一个方面（年收入、消费评分）。

聚类就是：只看特征，把"长得像"的样本归到一堆。

### 3. 簇（cluster，簇）——"物以类聚"出来的组

KMeans 分出来的每一组叫一个**簇**。好簇的标准：**簇内像**（组员彼此接近）、**簇间不像**（组与组离得远）。

注意：簇是算法算出来的，不是"正确答案"。它只保证"按你给的特征和距离算，这些点最像"，不保证这个分组有业务意义——那要靠人看结果来解释（第十二课的活）。

### 4. 聚类中心（centroid，聚类中心）——每个簇的"平均位置"

每个簇有一个中心点，坐标是簇内所有样本的**平均值**。可以理解成"这个组的队长站的位置"。样本离哪个中心近，就归哪个簇。

### 5. 距离（distance，距离）——"像不像"的尺子

KMeans 判断"谁跟谁像"用的是**欧氏距离**（两点之间的直线距离，初中几何那个）。点离某簇中心的直线距离越短，就越"像"那个簇。

### 6. 量纲（单位）——为什么必须标准化

看演示数据：年收入 50000 vs 80000，差 30000；消费评分 20 vs 30，差 10。按字面算距离，收入"差 30000"会把评分"差 10"彻底淹没——不是收入真的重要 3000 倍，只是它的**数字大**（量纲大，单位是元）。KMeans 只看距离，不看单位，所以先要把各特征拉回同一起跑线。

**标准化（standardize）**：每列减去本列均值、再除以本列标准差，

$$z = \frac{x - \text{均值}}{\text{标准差}}$$

做完每列都变成**均值 ≈ 0、标准差 ≈ 1**，谁也不靠"数字大"压人。

### 7. inertia（簇内平方和）——簇有多紧凑

`inertia_`（读"in-er-shia"，惯性的英文，这里借来当"松散程度"）：**每个样本到自己簇中心的距离平方，全部加起来**。簇越紧凑（组员越抱团），这个数越小。它是 KMeans 自带的"体检分数"，只用来比大小：同一份数据，分 3 簇的 `inertia_` 一定小于分 2 簇的（组多自然更紧凑），所以不能拿它跨 k 值比"谁更好"——怎么用它选 k，是下一课「肘部法则」的活。

### 8. KMeans 怎么干活——四步循环（了解即可，`fit` 内部自动完成）

1. 随机摆 k 个聚类中心；
2. **分派**：每个样本找最近的中心，进它的簇；
3. **挪中心**：每个中心挪到本簇样本的平均位置；
4. 重复 2~3，直到中心不再挪动（收敛）。

k（分几簇）是**人定的**，算法不会告诉你"分几簇最好"——这是 KMeans 最大的特点，也是最大的责任。

## 【核心内置函数拆解】

### ① `StandardScaler().fit_transform(X)` — 标准化：把各特征拉回均值 0、标准差 1

- **作用**：逐列做 $z = (x - \text{均值}) / \text{标准差}$，消除量纲差异，让"距离"不偏心大数字特征。
- **完整语法**：`scaler = StandardScaler()`（创建标准化器）→ `X_scaled = scaler.fit_transform(X)`（量尺寸 + 换算，一步完成）。其实是两步的合写：`fit`（量尺寸：算出每列的均值和标准差）+ `transform`（按尺寸换算）。本课用合写。
- **关键参数**：`X`——二维数据（形状 `(样本数, 特征数)`），DataFrame 或 numpy 数组都行。`StandardScaler()` 构造函数本身一般不用传参。
- **返回值**：numpy 二维数组，形状和 X 一样。**注意：就算传入 DataFrame，返回的也是 ndarray，列名丢了**。
- **常见坑**：
  - 返回值是数组不是表，想看列名要自己套 `pd.DataFrame(X_scaled, columns=...)`；
  - 打印均值时偶见 `-0.`（负零），它就是 0，不是错误（浮点数的小脾气）；
  - 属性 vs 方法（老坑）：`StandardScaler` 的 `mean_`、`scale_` 是 fit 之后才有的属性，不带括号。
- **适用场景**：任何靠"距离"干活的模型（KMeans、KNN）之前；特征量纲差异大时。

### ② `KMeans(n_clusters=k, random_state=42, n_init=10).fit(X)` — 聚类：把样本分成 k 簇

- **作用**：无监督地把 n 个样本分成 `n_clusters` 簇——喂的只有特征 X，**没有标签 y**。
- **完整语法**：`km = KMeans(n_clusters=3, random_state=42, n_init=10)`（创建聚类器）→ `km.fit(X_scaled)`（开始聚类）；或一行直接拿标签：`labels = KMeans(...).fit_predict(X_scaled)`。
- **关键参数**：
  - `n_clusters`：要分几簇，记作 k，必填。KMeans 不会帮你选 k，本课先人工指定（怎么科学地选，是下两课的活）；
  - `random_state`：随机种子。初始聚类中心是随机摆的，固定种子 → 结果每次一样（和 `train_test_split(random_state=...)` 同一条规则"同种子 → 同样结果"，只是控制对象不同：那个控制分组，这个控制初始中心）；
  - `n_init`：随机摆放初始中心的次数，跑 n 次取最好的那次。**写死 10**，避免不同 sklearn 版本默认值不一样导致结果不同。
- **返回值**：`.fit(X)` 返回模型本身（可以接着链式取属性）；`.fit_predict(X)` 直接返回簇标签一维数组（长度 = 样本数，值是 0 ~ k-1）。
- **常见坑**：
  - k 必须自己定，定错了结果就错——"分几簇"是业务问题 + 下两课的技术选法；
  - KMeans 用距离算像不像，**忘了标准化 = 大数字特征说了算**；
  - 对异常值敏感（一个极端值能把中心拽跑）。
- **适用场景**：客户分群、用户分层、商品分组……没有现成答案、想看"数据里天然有几坨"的场景。

### ③ `km.labels_` / `km.cluster_centers_` / `km.inertia_` — fit 之后的三张"成绩单"

- **作用**：聚类结果的三个属性——每人在哪簇、各簇中心在哪、各簇多紧凑。
- **完整语法**（**属性，不带括号！**）：`km.labels_`（每个样本的簇标签）、`km.cluster_centers_`（各簇的聚类中心坐标）、`km.inertia_`（簇内平方和）。
- **关键参数**：无（属性不收参数）。三个都是**尾下划线**命名——sklearn 的约定：带尾下划线的属性 = fit 之后才有。
- **返回值**：
  - `labels_`：一维数组，长度 = 样本数，值是 0 ~ k-1（哪一簇叫 0、哪一簇叫 1 是随机的，号码本身没有大小含义）；
  - `cluster_centers_`：形状 `(k, 特征数)` 的数组，第 i 行是第 i 簇的中心坐标（**标准化空间里的坐标**，不是原单位）；
  - `inertia_`：一个浮点数（上面第 7 点讲的簇内平方和）。
- **常见坑**：fit 之前访问这三个属性直接 `AttributeError`（属性还不存在）；`cluster_centers_` 是标准化后的坐标，想回原单位要看懂"标准化空间"再换算。
- **适用场景**：把簇标签贴回原表逐个查看、看簇中心给每簇起名字、用 `inertia_` 看簇的紧凑程度。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第九课演示：KMeans 聚类从 0 到 1 ============
import numpy as np                                          # 数值计算库
import pandas as pd                                         # 表格处理库
from sklearn.preprocessing import StandardScaler            # 标准化工具（sklearn 的预处理模块）
from sklearn.cluster import KMeans                          # KMeans 聚类算法（sklearn 的聚类模块）

# ---------- 第 1 步：准备数据（6 位顾客的两个特征） ----------
df = pd.DataFrame({                                        # 造一张 6 行 2 列的表
    '年收入（元）': [50000, 80000, 120000, 300000, 350000, 400000],  # 特征 1：数值范围 5 万~40 万
    '消费评分': [20, 25, 30, 70, 75, 80],                  # 特征 2：数值范围 20~80
})
print(df)                                                  # 看整张表
print(df.dtypes)                                           # 看每列数据类型（应为数值）

# ---------- 第 2 步：标准化（消除量纲差异） ----------
scaler = StandardScaler()                                  # 函数①：创建标准化器
X_scaled = scaler.fit_transform(df)                        # 函数①：一步完成"量尺寸 + 换算"
print(X_scaled.round(2))                                   # 打印标准化后的数值（保留 2 位小数）
print('各列均值:', X_scaled.mean(axis=0).round(4))          # 标准化后各列均值约等于 0
print('各列标准差:', X_scaled.std(axis=0).round(4))         # 标准化后各列标准差约等于 1

# ---------- 第 3 步：KMeans 聚类 ----------
km = KMeans(n_clusters=2, random_state=42, n_init=10)      # 函数②：创建聚类器（目标分成 2 簇）
km.fit(X_scaled)                                           # 函数②：开始聚类（只喂特征 X，没有标签 y！）
print('每个样本的簇标签:', km.labels_)                       # 属性①：6 个样本各属于哪一簇
print('聚类中心（标准化后）:')                               # 属性②：每个簇的中心坐标
print(km.cluster_centers_.round(2))
print('inertia_（簇内平方和）:', round(km.inertia_, 2))      # 属性③：各簇紧凑程度

# ---------- 第 4 步：把结果并回原表看 ----------
df['簇'] = km.labels_                                      # 给每个样本贴上簇标签
print(df)                                                  # 一眼看出两簇各是谁
```

## 【本节重点总结】

1. 无监督学习没有标签 y，KMeans 只看特征把样本分成 k 簇，靠的是"距离近 = 像"。
2. 上 KMeans 之前必须 `StandardScaler` 标准化——不然大数字特征霸占距离，分簇全听它的。
3. 三张成绩单背下来：`labels_`（谁在哪簇）、`cluster_centers_`（各簇中心）、`inertia_`（多紧凑），都是 fit 之后的属性，不带括号。
