# 第六课：岭回归与 Lasso

## 【本节核心知识点】

正则化（regularization）= 在"拟合数据"的目标之外给系数加一条"别太放飞"的惩罚：**Ridge（岭回归）把系数整体往 0 压但不归零，Lasso 能把没用特征的系数直接压成 0**，`alpha` 控制惩罚力度。

## 【核心概念讲解】

### 1. 先看问题：过拟合（overfitting）

上一课有个现象还记得吗——训练集分数总比测试集好看。程度轻是正常，程度重就叫**过拟合**：模型把训练数据学得太死，**连噪声都背下来了**。

- **噪声**（noise）：数据里的随机波动，不是规律。比如同一个学习时长，成绩上下浮动几分，那几分就是噪声。
- 生活类比：背题的学生（overfitting，把练习册答案全背下来）vs 学懂公式的学生（underfitting，没学会）。背题的在练习册上满分（训练集分数虚高），一上考场（新数据）就露馅——**他背的是噪声，不是规律**。
- 过拟合的一个典型症状：**系数特别大**。模型为了让直线精准穿过每个训练点，把系数拧得飞起来硬凑噪声。反过来说：**摁住系数 = 治过拟合的一个思路**。

### 2. 正则化：给系数上一把锁

正则化就是在原来的目标上加一个**惩罚项**（penalty，专门罚"系数太大"）：

$$\text{总目标} = \text{预测误差} + \alpha \times \text{系数惩罚}$$

- **alpha**（读"阿尔法"，惩罚系数）：控制惩罚力度。`alpha = 0` 时惩罚消失，退回普通线性回归；`alpha` 越大，系数被压得越狠。
- 两种压法，对应两个模型：

| 模型 | 惩罚什么 | 效果 | 一句话 |
|---|---|---|---|
| **Ridge**（岭回归） | 系数的**平方和**（L2） | 所有系数均匀缩小，**都不会变成 0** | 雨露均沾地压 |
| **Lasso** | 系数的**绝对值和**（L1） | 小系数**直接压成 0** | 顺手把没用的特征踢出局 |

- Lasso 把系数压成 0，等于宣布"这个特征我没用上"——这叫**特征选择**（feature selection）：一堆特征里自动挑出有用的。
- 怎么知道模型学到了真规律还是噪声？看 `coef_` 对比表：**把三个模型的系数和"真实系数"摆一起**，谁接近真值谁在学规律，谁给噪声特征配上了大系数谁在背噪声。

### 3. 两个随机种子，别混（提前打预防针）

本课要自己造数据了，会遇到随机数。规矩一句话：**同种子 → 同结果，不同种子 → 不同结果**。

| 随机工具 | 管什么 | 本课用在哪 |
|---|---|---|
| `np.random.default_rng(42)` | **造出来的数值**长什么样 | 生成 20 行特征和噪声 |
| `train_test_split(random_state=0)` | 哪些**行**进训练/测试集 | 本课没用到，第五课用过 |

两者各管一摊，谁也替代不了谁。下面代码里的种子小实验会亲眼验证这条规矩。

## 【核心内置函数拆解】

### ① `Ridge(alpha=1.0)` — 岭回归（L2 正则化）

- **作用**：带 L2 惩罚的线性回归，把系数整体往 0 压，防过拟合。
- **完整语法**：`Ridge(alpha=1.0, fit_intercept=True)`，用法和 `LinearRegression` 一模一样：`Ridge(alpha=...).fit(X, y)`。
- **关键参数**：
  - `alpha`：惩罚力度，默认 1.0。0 = 退回普通线性回归；越大系数越小。
  - `fit_intercept`：是否拟合截距，默认 True，一般不动。
- **返回值**：模型对象（unfitted（未训练的）模型），接着 `.fit()` 才能用。
- **常见坑**：
  1. `alpha` 越大系数越小，但**永远不会恰好变成 0**——想要归零看 Lasso；
  2. Ridge 的 `alpha` 和 Lasso 的 `alpha` **不能直接比大小**：两者目标函数的写法不同（Lasso 多除了个 `2n`），同一个 alpha 压出来的力度不一样。
- **适用场景**：特征都有点用、但怕系数太大背噪声的时候；尤其特征之间关系紧密（共线性）时很稳。

### ② `Lasso(alpha=1.0)` — Lasso 回归（L1 正则化）

- **作用**：带 L1 惩罚的线性回归，能把没用特征的系数**压成 0**，自带特征选择。
- **完整语法**：`Lasso(alpha=1.0, fit_intercept=True, max_iter=10000)`。
- **关键参数**：
  - `alpha`：惩罚力度，默认 1.0。本课数据用 0.1 上下比较合适。
  - `max_iter`：最大迭代次数。Lasso 是"一点点磨"出解的，复杂数据默认 1000 次可能不够，会弹 `ConvergenceWarning`（不收敛警告）——直接给 10000 一劳永逸。
- **返回值**：模型对象，同样 `.fit()` 后可用。
- **常见坑**：
  1. `alpha` 调太大，把**有用特征也误伤**（系数被压到接近 0）——练习里你能亲眼看到；
  2. 想要"恰好 0.0"的系数，判断用 `coef_[i] == 0`，打印出来可能是 `-0.0`，负零也是零，判定照样为 True。
- **适用场景**：特征一堆、想自动筛出重要特征的时候。

> `fit` / `predict` / `coef_` / `intercept_` 还是第一课那套：`fit` = 学习，`predict` = 答题，`coef_`（系数）/ `intercept_`（截距）是**属性，不加括号**，训练完才存在。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第六课：岭回归与 Lasso ============
import numpy as np                         # 数组工具
import pandas as pd                        # 表格工具（摆系数对比表）
from sklearn.linear_model import LinearRegression, Ridge, Lasso  # 三个模型：普通/岭/Lasso

# ---------- 0. 种子小实验：同种子→同结果，不同种子→不同结果 ----------
print('===== 种子小实验 =====')
a = np.random.default_rng(42).normal(size=3)   # 种子 42，第一次造 3 个正态随机数
b = np.random.default_rng(42).normal(size=3)   # 种子 42，第二次
c = np.random.default_rng(7).normal(size=3)    # 种子 7
print('种子 42 第一次 :', np.round(a, 4).tolist())  # tolist()：numpy 数组转普通列表，打印干净
print('种子 42 第二次 :', np.round(b, 4).tolist())  # 和上一行一模一样
print('种子 7        :', np.round(c, 4).tolist())  # 换种子就换一批数

# ---------- 第一部分：手算对照，看 alpha 怎么压系数 ----------
print()
print('===== 第一部分：y = 2x + 1，Ridge 把系数往 0 压 =====')
x = np.array([1, 2, 3, 4])                 # 特征
y = 2 * x + 1                              # 标签，严格 y = 2x + 1，一点噪声没有
X = x.reshape(-1, 1)                       # 转二维（第一课函数②）

ols = LinearRegression()                   # 造普通线性回归
ols.fit(X, y)                              # 训练
print('OLS          coef =', ols.coef_.tolist(),              # coef_：系数（属性，不加括号）
      'intercept =', round(float(ols.intercept_), 4))        # intercept_：截距

for alpha in [0.5, 1, 5, 10]:              # 惩罚力度从轻到重
    ridge = Ridge(alpha=alpha)             # 函数①：造岭回归模型
    ridge.fit(X, y)                        # 训练
    print(f'Ridge α={alpha:<4} coef =', np.round(ridge.coef_, 4).tolist(),
          'intercept =', round(float(ridge.intercept_), 4),
          '| 手算 10/(5+α) =', round(10 / (5 + alpha), 4))    # 手算公式当场对照

ridge5 = Ridge(alpha=5).fit(X, y)          # 造模型+训练一步写完（fit 返回模型本身）
print('Ridge(α=5) 预测 x=3 :', np.round(ridge5.predict([[3]]), 4).tolist(),  # 函数③
      '| 手算 1.0×3 + 3.5 = 6.5')

# ---------- 第二部分：4 个特征里 2 个是纯噪声，三模型对比 ----------
print()
print('===== 第二部分：噪声特征对比 =====')
rng = np.random.default_rng(42)            # 种子固定，你我结果一样
X4 = rng.normal(size=(20, 4))              # 20 个样本 × 4 个特征（x1 x2 有用，x3 x4 是噪声）
y4 = 3 * X4[:, 0] - 2 * X4[:, 1] + rng.normal(scale=0.5, size=20)  # 真实规律：3x1 − 2x2 + 小噪声

ols4 = LinearRegression().fit(X4, y4)      # 普通线性回归
ridge4 = Ridge(alpha=1).fit(X4, y4)        # 函数①：岭回归
lasso4 = Lasso(alpha=0.1, max_iter=10000).fit(X4, y4)  # 函数②：Lasso 回归

tab = pd.DataFrame({                       # 系数对比表：每行一个特征
    '真实系数': [3, -2, 0, 0],             # 造数据时的真值（x3 x4 是噪声，真系数 0）
    'OLS':   np.round(ols4.coef_, 3),      # 普通线性回归的估计
    'Ridge': np.round(ridge4.coef_, 3),    # 岭回归的估计
    'Lasso': np.round(lasso4.coef_, 3),    # Lasso 的估计
}, index=['x1', 'x2', 'x3(噪声)', 'x4(噪声)'])
print(tab.to_string())                     # 打印对比表（不截断）
```

### 手算对照（alpha 的力度是公式算出来的，不是玄学）

**第一部分**：数据 `x = [1, 2, 3, 4]`，`y = 2x + 1 = [3, 5, 7, 9]`。

- $\bar{x} = 2.5$，$S_{xx} = (-1.5)^2 + (-0.5)^2 + 0.5^2 + 1.5^2 = 5$
- $\bar{y} = 6$，$S_{xy} = 2 \times S_{xx} = 10$（因为 y 正好是 2x+1，斜率 2）
- Ridge 一元公式（推导不展开，记结构就行）：**系数 $w = \dfrac{S_{xy}}{S_{xx} + \alpha} = \dfrac{10}{5 + \alpha}$**，截距 $b = \bar{y} - w\bar{x} = 6 - 2.5w$

| α | 手算 w = 10/(5+α) | 实测 `coef_` | 手算 b = 6 − 2.5w | 实测 `intercept_` | 判定 |
|---|---|---|---|---|---|
| 0（就是 OLS） | 10÷5 = 2.0 | 2.0 | 6 − 5.0 = 1.0 | 1.0 | ✅ 精确 |
| 0.5 | 10÷5.5 = 1.8182 | 1.8182 | 6 − 4.5455 = 1.4545 | 1.4545 | ✅ |
| 1 | 10÷6 = 1.6667 | 1.6667 | 6 − 4.1667 = 1.8333 | 1.8333 | ✅ |
| 5 | 10÷10 = 1.0 | 1.0 | 6 − 2.5 = 3.5 | 3.5 | ✅ 精确 |
| 10 | 10÷15 = 0.6667 | 0.6667 | 6 − 1.6667 = 4.3333 | 4.3333 | ✅ |

预测对照：`Ridge(α=5)` 预测 x=3 → 手算 $1.0 \times 3 + 3.5 = 6.5$，实测 `[6.5]` ✅ 精确命中。

**一眼看懂**：分母 $S_{xx} + \alpha$，alpha 越大分母越大、系数越小——**alpha 就是往分母上加的那块石头**。同时 OLS（α=0）的 2.0 恰好是真系数，说明没惩罚时模型学得准（这数据没噪声，所以 OLS 也没病可治）。

**第二部分**：这一节的"手算对照"就是**造数据时的真值** `(3, -2, 0, 0)`——你手里有答案，看三个模型谁还原得出来：

| 看什么 | OLS | Ridge | Lasso | 结论 |
|---|---|---|---|---|
| 信号特征 x1 | 3.078 | 2.777 | 2.848 | 都学到了规律（真值 3），Ridge/Lasso 稍微缩水 |
| 信号特征 x2 | -2.118 | -1.852 | -1.903 | 同上（真值 −2），负号也保住了 |
| 噪声特征 x3 | 0.075 | 0.123 | **0.000** | OLS 被噪声骗了，Lasso 直接归零 |
| 噪声特征 x4 | 0.106 | 0.103 | **0.000** | 同上 |

**三个值得注意的现象**：

1. **Lasso 把 x3、x4 精确压成 0.000**——特征选择不是玄学，是 L1 惩罚的直接后果。
2. **Ridge 谁也不归零**：x3、x4 还挂着 0.123、0.103。而且注意 x3 那格 Ridge 的 0.123 甚至比 OLS 的 0.075 还大——**Ridge 只管"整体缩小"，不保证每个系数都比 OLS 小**（特征之间有相关性时会出现这种小反弹）。别把 Ridge 理解成"逐个压小"。
3. **alpha 过大会误伤**：练习里把 Lasso 的 alpha 调大，你会看到 x2（明明有用）的系数也跟着缩——惩罚是无差别的，调参（tuning）就是找"压噪声"和"保信号"的平衡点。

## 补充答疑：L1 和 L2 到底是什么意思？（2026-10-25）

**一句话**：L1、L2 是两种"量系数有多大"的尺子（数学里叫范数（norm）），编号就是"几次方"——L1 量的是**绝对值和**，L2 量的是**平方和**（再开根）。所以"L1 惩罚"= 按绝对值和罚，"L2 惩罚"= 按平方和罚。

### 1. 为什么要给系数"量大小"

惩罚项要罚"系数太大"，就得先量出系数有多大。一堆系数 $w_1, w_2, \dots, w_n$ 合在一起在数学上叫**向量**（vector，一串数），专门量向量"大小"的尺子就叫**范数**（norm）。L1、L2 是范数家族里最常用的两把。

### 2. 两把尺子怎么量

拿一组假系数 $w = [0.5,\ -2,\ 3]$ 举例：

| 尺子 | 计算规则 | 手算过程 | 量出的值 |
| --- | --- | --- | --- |
| **L1 范数** | 绝对值求和 $\sum \lvert w_i \rvert$ | $0.5 + 2 + 3$ | $5.5$ |
| **L2 范数** | 平方和开根 $\sqrt{\sum w_i^2}$ | $\sqrt{0.25 + 4 + 9}$ | $\approx 3.64$ |
| **L2 范数的平方**（Ridge 真正用的） | 平方和 $\sum w_i^2$ | $0.25 + 4 + 9$ | $13.25$ |

**规律**：L 后面的数字 = 每个系数自乘的次数。L1 自乘 1 次（等于不乘，只取绝对值），L2 自乘 2 次（平方）。

### 3. 对应到两个模型

| 模型 | 惩罚项公式 | 叫法 |
| --- | --- | --- |
| Lasso | $\alpha \times \sum \lvert w_i \rvert$（L1 范数） | L1 惩罚 / L1 正则化 |
| Ridge | $\alpha \times \sum w_i^2$（L2 范数的平方） | L2 惩罚 / L2 正则化 |

> 💡 **常见坑**：资料里 Ridge 的惩罚项常写成 $\sum w_i^2$，不带开根号——它是"L2 范数的**平方**"，省掉开根是为了求导（求最优解的数学操作）方便，效果一样，看到别慌。

### 4. 代码验证（`.venv` 真实运行）

```python
import numpy as np                                     # 导入 numpy

w = np.array([0.5, -2, 3])                             # 假装这是训练出来的 3 个系数（一串数 = 向量）
print('系数：', w)                                     # 打印这组系数
print('L1 范数（绝对值和）np.abs(w).sum()      =', np.abs(w).sum())          # 函数：np.abs 取绝对值，.sum() 求和
print('L2 范数（平方和开根）np.sqrt((w**2).sum()) =', np.sqrt((w**2).sum()))  # 函数：** 平方后求和，np.sqrt 开根号
print('L2 范数的平方（Ridge 实际惩罚项）(w**2).sum() =', (w**2).sum())        # Ridge 用的就是这个平方和
print('对照：Lasso 惩罚项 α*Σ|w|，α=2 时 =', 2 * np.abs(w).sum())            # α × L1 范数
print('对照：Ridge 惩罚项 α*Σw²，α=2 时 =', 2 * (w**2).sum())                # α × L2 范数的平方
```

真实运行结果：

```
系数： [ 0.5 -2.   3. ]
L1 范数（绝对值和）np.abs(w).sum()      = 5.5
L2 范数（平方和开根）np.sqrt((w**2).sum()) = 3.640054944640259
L2 范数的平方（Ridge 实际惩罚项）(w**2).sum() = 13.25
对照：Lasso 惩罚项 α*Σ|w|，α=2 时 = 11.0
对照：Ridge 惩罚项 α*Σw²，α=2 时 = 26.5
```

每个数字都能手算对上：$0.5 + 2 + 3 = 5.5$，$0.25 + 4 + 9 = 13.25$，$\alpha=2$ 时分别乘 2 得 11.0 和 26.5。（`[ 0.5 -2.   3. ]` 是 numpy 的数组显示格式，数字间的空格长短不用管。）

## 【本节重点总结】

1. 正则化 = 预测误差 + α × 系数惩罚，alpha 越大系数被压得越狠，alpha=0 就退回普通线性回归。
2. Ridge（L2）雨露均沾地缩小所有系数但不归零；Lasso（L1）能把没用特征的系数压成 0，顺手做特征选择。
3. 系数对比表（三模型 `coef_` vs 真实系数）是体检报告：谁接近真值谁在学规律，谁给噪声配大系数谁在背噪声。
