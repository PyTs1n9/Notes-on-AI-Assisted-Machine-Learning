# 第十一课：轮廓系数与 DBI

## 【本节核心知识点】

肘部看不清时用第二、第三把尺子给 K 打分：**轮廓系数**（每簇"内紧外松"的程度，越大越好，找**峰值**）和 **DBI**（簇与簇有多"像"，越小越好，找**谷值**），再和肘部结论三证合一定最佳 K。

## 【核心概念讲解】

### 1. 肘部法则的短板

肘部法则靠肉眼找"由陡变缓"的拐弯。可现实数据的曲线常常是慢慢变平的**圆弧**，没有明显拐点——十个人看能读出三个不同的 K。所以需要**能直接打分**的尺子。

### 2. 轮廓系数（silhouette score，轮廓系数）——"内紧外松"打分器

先看**单个样本**怎么打分。假设有两个距离要量：

- **a** = 本样本到**本簇其他样本**的平均距离（簇内平均距离）——a 越小，说明它越"贴着自己人"；
- **b** = 本样本到**最近的另一个簇**所有样本的平均距离（最近异簇平均距离）——b 越大，说明它越"远离外人"。

把两者合成一个数：

$$s = \frac{b - a}{\max(a, b)}$$

（分母取 a、b 中较大的那个，保证 s 不超过 1。）s 的范围是 **[-1, 1]**，读法：

| s 的位置 | 含义 |
|---|---|
| 接近 1 | 贴着自己人、离外人远（分得好） |
| 接近 0 | 骑在两簇边界上（分得糊） |
| 小于 0 | 它离别的簇更近——多半**分错了** |

**silhouette score** = 全体样本 s 的平均值。它随 K 的变化是"**峰形**"：K 太小，大簇里混着好几坨，a 大 → 分低；K 太大，把本来完整的一坨切碎，b 小 → 分也低；**中间的峰值就是最佳 K**。

### 3. DBI（Davies-Bouldin Index，戴维斯-布尔丁指数）——"簇间相似度"打分器

通俗流程：

1. 每簇量一下"自己有多散"（簇内散度 S：组员离中心的平均距离）；
2. 每簇去找**跟自己最像的那一簇**（散度大、中心又近 = 像），算相似度：两家的散度之和 ÷ 两家中心的距离；
3. 所有簇的相似度取平均 = **DBI**。

分子是"两家各有多散"，分母是"两家隔多远"——**散度小、间距大，比值才小**。所以 DBI **越小越好**（理论下限 0）。它随 K 的变化是"**谷形**"，**谷值处就是最佳 K**。

### 4. 三把尺子方向大不同——这张表必须背

| 尺子 | 好的方向 | 随 K 的形状 | 怎么找 K |
|---|---|---|---|
| `inertia_` | 越小越紧凑（但 K 越大必然越小） | 一路降 | 看**肘部**（由陡变缓） |
| 轮廓系数 | **越大越好**（上限 1） | 峰形 | 找**峰值** |
| DBI | **越小越好**（下限 0） | 谷形 | 找**谷值** |

记法：**轮廓向上看峰，DBI 向下看谷**。混了方向，选 K 就全反了。

### 5. 三证合一定 K

数据里真有结构时，三把尺子会指向同一个 K（演示里全指向 K=3）。如果三者打架，说明数据的结构本身就模糊——这时别硬选，回去看业务、看可视化（第十二课），或者承认"分几群都行"。

### 6. 两个指标的共同前提

和 KMeans 一样，它们量的都是**距离**——所以标准化照做不误；并且 K=1（只有一个簇）或 K=样本数（每人一簇）时没法算，循环从 2 起正好绕开。

### 补充答疑：「峰形」到底是怎么来的（2026-10-27 答疑补充）

原文说"K 太小 a 大、K 太大 b 小"，为什么？把 a、b 拿出来，跟着 K 走一遍就明白了。记住 s 的公式 $s = (b - a) / \max(a, b)$：**a 越小越好，b 越大越好**。K 一变，簇的切法就变，a、b 跟着变：

1. **K 太小 = merge（合并）过头**：现实里两坨不同的数据被并进同一个簇。对样本来说，"自己人"里混进了另一坨离它远的人，平均下来 **a 被拉大** → 分子 b−a 变小 → s 低。（原文的"大簇里混着好几坨，a 大"就是这个意思。）
2. **K 刚好**：自己人全是真自己人（**a 小**），最近的外人是另一整坨、离得远（**b 大**）→ s 大，接近 1。
3. **K 太大 = split（切开）过碎**：本来完整的一坨被切成两半。样本的 b 是"最近的另一个簇"的平均距离——而最近的那个簇就是隔壁那半坨，它其实是自己人、只是被切出去了，所以 **b 被压小**，甚至 b < a、s 变负。→ s 低。（原文的"把本来完整的一坨切碎，b 小"就是这个意思。）

分班比喻：一个年级真实是 3 个班。硬并成 2 个班 → 某个班里坐着两拨互相不熟的人（a 大）；硬拆成 6 个班 → 隔壁"班"坐的就是你原来的同桌（b 小）；正好 3 个班 → 每班都是熟人、班与班隔得远（a 小 b 大）。

所以把 silhouette score 对 K 画成曲线：两端塌、中间鼓，鼓包的顶点（peak，峰值）就是最佳 K——正文演示里 K=3 取到 0.7982，就是那个顶。

## 【核心内置函数拆解】

### ① `silhouette_score(X, labels)` — 全体样本的平均轮廓系数

- **作用**：给"一种分法"整体打分——衡量簇内紧、簇间松，越大越好。
- **完整语法**：`from sklearn.metrics import silhouette_score`（sklearn 的 metrics（度量）模块）→ `silhouette_score(X, labels)`。
- **关键参数**：`X`——特征数据（**标准化后的**，和 KMeans 同口径）；`labels`——簇标签数组（一般传 `km.labels_`）。
- **返回值**：一个浮点数，范围 [-1, 1]，越大越好。
- **常见坑**：
  - K=1 或 K=样本数时没意义（会报错），所以循环 `range(2, 11)`；
  - `labels` 必须是**同一次聚类**给出的——拿 K=5 的 `labels_` 去配 K=4 那次的 X 直接报错（长度都对不上）；
  - 忘标准化 = 大数字特征又来霸占距离（老坑）。
- **适用场景**：给候选 K 逐个打分，找峰值。

### ② `davies_bouldin_score(X, labels)` — 簇间相似度的平均（越小越好）

- **作用**：从"簇与簇像不像"的角度打分——散度大、间距小的分法扣分，越小越好。
- **完整语法**：`from sklearn.metrics import davies_bouldin_score` → `davies_bouldin_score(X, labels)`。
- **关键参数**：同 `silhouette_score`——`X`（标准化后特征）、`labels`（同一次聚类的 `km.labels_`）。
- **返回值**：一个浮点数，理论下限 0，**越小越好**（方向和轮廓系数相反！）。
- **常见坑**：方向记反是头号坑——它是"扣分器"不是"得分器"；参数坑同 ①。
- **适用场景**：和轮廓系数互相印证，一起定 K。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第十一课演示：轮廓系数与 DBI 给顾客数据再定一次 K ============
import numpy as np                                          # 数值计算库
import pandas as pd                                         # 表格处理库
from sklearn.preprocessing import StandardScaler            # 标准化工具
from sklearn.cluster import KMeans                          # KMeans 聚类算法
from sklearn.metrics import silhouette_score                # 函数①：轮廓系数
from sklearn.metrics import davies_bouldin_score            # 函数②：DBI

# ---------- 1. 读数据 + 标准化（老流程） ----------
df = pd.read_csv('customers.csv', encoding='utf-8-sig')     # 还是第九课那份顾客数据
scaler = StandardScaler()                                  # 创建标准化器
X_scaled = scaler.fit_transform(df)                        # 标准化：拉回均值 0、标准差 1

# ---------- 2. 循环 K=2~10，给每种分法打两个分 ----------
Ks = list(range(2, 11))                # K=1 和 K=样本数没法打分，从 2 起
sils = []                              # 收集各 K 的轮廓系数
dbis = []                              # 收集各 K 的 DBI
for k in Ks:                           # 依次取 2, 3, ..., 10
    km = KMeans(n_clusters=k, random_state=42, n_init=10)  # 参数照旧钉死
    km.fit(X_scaled)                                      # 聚类
    sils.append(round(silhouette_score(X_scaled, km.labels_), 4))    # 函数①：越大越好
    dbis.append(round(davies_bouldin_score(X_scaled, km.labels_), 4)) # 函数②：越小越好

# ---------- 3. 打印成绩单 ----------
print('K    轮廓系数    DBI')                              # 表头
for k, s, d in zip(Ks, sils, dbis):                        # 三列并排走
    print(f'K={k:<3d} {s:<10} {d}')

# ---------- 4. 程序自动找峰值和谷值 ----------
best_sil = Ks[sils.index(max(sils))]   # max 找最大值，.index 找它在列表里的位置
best_dbi = Ks[dbis.index(min(dbis))]   # min 找最小值
print(f'轮廓系数峰值：K={best_sil}（{max(sils)}）')
print(f'DBI 谷值：K={best_dbi}（{min(dbis)}）')

# ---------- 5. 读结果 ----------
print('两把尺子指向同一个 K，再对上第十课的肘部（K=3）——三证合一，最佳 K=3。')
```
