# 第三课：Pandas 入门——Series 与 DataFrame

## 【本节核心知识点】
Pandas 是"用代码操作 Excel 表格"的库，核心只有两个数据结构：`Series`（一列带标签的数据）和 `DataFrame`（一张表格）；用 `pd.Series` / `pd.DataFrame` 造表，用 `head / info / describe` 和 `shape / columns / dtypes` 快速查看表格。

## 【核心概念讲解】

### Pandas 是什么？为什么机器学习要学它？
到目前为止我们处理数据用的是 numpy 数组——但数组只有"位置"（第 0 行第 1 列），没有"名字"。真实世界的数据都是**表格**：Excel 表、CSV 文件，每列有列名（姓名、数学、英语），每行有行号。**Pandas 就是"用代码操作表格"的库**，可以把它理解成"编程版 Excel"，但行数百万也不卡。

机器学习离不开它，因为实战流程的第一步都是：**读数据集（CSV/Excel）→ 查看和清洗 → 交给 sklearn 训练**。Pandas 负责前两步，sklearn 负责第三步。

| 术语 | 通俗解释 | 长什么样 |
|---|---|---|
| **Series** | **一列**带标签的数据，像 Excel 的一列 | `小明 90 / 小红 85 / 小刚 78` |
| **DataFrame** | **一整张表格**，由多列 Series 组成 | 姓名、数学、英语各一列拼成的表 |
| **索引（index）** | 每行的"名字"，默认是 0、1、2… 自动编号 | 表格最左边那一列 |
| **列名（columns）** | 每列的"名字" | `姓名`、`数学`、`英语` |
| **dtype（数据类型）** | 每列存的是什么类型：整数 int64、小数 float64、文字 str | `df.dtypes` 能看到 |
| **缺失值（NaN）** | 空缺的数据，"Not a Number" 的缩写 | 某个学生缺考，成绩就是 NaN |

**Series 和 DataFrame 的关系**：一个 DataFrame 就是若干列 Series 拼成的表。只关心一列时用 Series（像一维数组），看整张表时用 DataFrame（像二维表格）。它们和 numpy 的关系：**numpy 数组只有数字和位置，pandas 表格多了行名、列名和类型**。

## 【核心内置函数拆解】

### ① `pd.Series(data, index=None, name=None, dtype=None)` — 造一列带标签的数据
- **作用**：把一组数据变成"一列带行名的表"，是 DataFrame 的一列。
- **完整语法**：`pd.Series(data, index=None, name=None, dtype=None)`
- **关键参数**：
  - `data`：数据，可以是列表 `[90, 85, 78]`、numpy 数组、字典；
  - `index`：每行的名字（标签），不写就自动编号 0、1、2…；
  - `name`：这一列叫什么（列名）；
  - `dtype`：元素类型，一般不写，自动推断。
- **返回值**：一个 Series 对象。
- **常见坑**：`index` 的个数必须和数据个数一样多，否则报错；行名可以重复，但之后按名字取数会出怪事，尽量别重复。
- **适用场景**：只想处理"一列数据"时（比如单独看数学成绩这一列）。

### ② `pd.DataFrame(data, columns=None, index=None)` — 造一张表格
- **作用**：把多列数据拼成一张表格，本课的主角。
- **完整语法**：`pd.DataFrame(data, columns=None, index=None)`
- **关键参数**：
  - `data`：最常用**字典**——键 = 列名，值 = 该列的数据列表，如 `{'数学': [90, 85], '英语': [76, 92]}`；
  - `columns`：指定列的顺序（不写就按字典键的顺序）；还能用它"选列"或"加空列"；
  - `index`：行名，不写就自动编号 0、1、2…。
- **返回值**：一个 DataFrame 对象。
- **常见坑**：
  1. ⚠️ 字典里各列的**长度必须一样长**（5 个人的姓名配 4 个分数就报错）；
  2. 列名是字符串，记得加引号；
  3. `data` 也可以传"列表的列表"（每行一个列表），但那时列名要靠 `columns` 单独给，入门先用字典写法，不容易乱。
- **适用场景**：手里有"若干列数据"想拼成表格时；实际工作中更多是用 `pd.read_csv()` 读现成文件（下节课讲）。

### ③ `df.head(n=5)` / `df.tail(n=5)` — 看前 / 后几行
- **作用**：只看表格的开头/结尾几行，快速确认"表长什么样"。
- **完整语法**：`df.head(n=5)`、`df.tail(n=5)`
- **关键参数**：`n` —— 看几行，默认 5。
- **返回值**：**一个新的 DataFrame**（前/后 n 行），原表不动。
- **常见坑**：`head()` 没有参数就是看前 5 行，不是 1 行；行数超过表格总行数也不会报错，直接全给你。
- **适用场景**：拿到任何新表格的第一件事——先 `head()` 看一眼，别急着算。

### ④ `df.info()` — 表格的"体检报告"
- **作用**：一行不漏地汇报：共几行、每列叫什么、每列有多少个**非空**数据、每列什么类型、占多少内存。
- **完整语法**：`df.info(verbose=None, ...)`（一般不带参数直接用）
- **返回值**：⚠️ **什么都不返回（None）**，报告直接打印到屏幕上。
- **常见坑**：写成 `print(df.info())` 会在报告末尾多打印一个 `None`——因为它是"打印给你看"而不是"算个值给你"，不需要套 print。
- **适用场景**：想知道"哪些列有缺失值、每列是什么类型"时，看一眼 info 全明白。

### ⑤ `df.describe()` — 数值列的统计摘要
- **作用**：对所有**数值列**一次算好 8 个统计量：count（个数）、mean（平均）、std（标准差，衡量数据有多"散"）、min/max（最小/最大）、25%/50%/75%（分位数，把数据从小到大排队后不同位置的值；50% 又叫中位数）。
- **完整语法**：`df.describe(percentiles=None, include=None)`（一般不带参数直接用）
- **返回值**：一个新的 DataFrame，行是统计量、列是原来的数值列。
- **常见坑**：⚠️ 默认**只统计数值列**——`姓名` 这种文字列不会出现在结果里，不是丢了，是它没法算平均值。
- **适用场景**：拿到表格想 3 秒钟了解"每列数据大概什么水平、有没有异常值"。

### ⑥ `df.shape` / `df.columns` / `df.dtypes` — 查看表格"骨架"的属性
- **作用**：不计算、只查看表格的基本信息（像第一课的 `coef_` 一样是**属性**，不是函数）。
- **返回值**：
  - `df.shape`：元组 `(行数, 列数)`，如 `(5, 4)`；
  - `df.columns`：所有列名（Index 对象），`.tolist()` 转成普通列表；
  - `df.dtypes`：每列的数据类型。
- **常见坑**：⚠️ **属性不加括号**！`df.shape` ✅ / `df.shape()` ❌ 报错。这是初学者最常见的手滑。
- **适用场景**：任何时候想快速确认"几行几列、列名对不对、类型对不对"。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第三课：Pandas 入门——Series 与 DataFrame ============
import pandas as pd                                    # pandas：专门处理"表格"的库（惯例缩写 pd）

# ---- 1) Series：一列带标签的数据 ----
s = pd.Series([90, 85, 78], index=['小明', '小红', '小刚'], name='数学')  # 函数①：造一列数据
print(s)                                               # 打印整个 Series
print("s 的类型:", type(s))                             # type() 查看对象类型，确认是 pandas.Series

# ---- 2) DataFrame：一张表格 ----
df = pd.DataFrame({                                    # 函数②：用"字典"造表，键=列名，值=该列数据
    '姓名': ['小明', '小红', '小刚', '小丽', '小强'],
    '数学': [90, 85, 78, 92, 88],
    '英语': [76, 92, 80, 85, 79],
    'Python': [88, 95, 70, 90, 82],
})
print(df)                                              # 打印整张表（最左边 0~4 是自动编号的行号）

# ---- 3) 快速查看"骨架" ----
print(df.head(2))                                      # 函数③：只看前 2 行
print("形状:", df.shape)                                # 函数⑥：(行数, 列数)，属性不加括号
print("列名:", df.columns.tolist())                     # 函数⑥：列名转成普通列表
print("各列类型:")                                      # 函数⑥：每列的数据类型
print(df.dtypes)

# ---- 4) 体检报告 ----
df.info()                                              # 函数④：直接打印报告，不返回值（外面别套 print）

# ---- 5) 数值统计摘要 ----
print(df.describe())                                   # 函数⑤：数值列的统计摘要（姓名列不会出现）
print("手算数学平均分:", (90 + 85 + 78 + 92 + 88) / 5)   # 433/5 = 86.6，对照 describe 里的 mean
```

#### 老师答疑（2026-10-23）

**你的疑问**：`describe()` 打印出了电影名，而且没有 mean 那几行。

**一句话答案**：不是 pandas 出错——票价、评分的数据加了引号被存成了**文字**，`describe()` 对文字列不算 mean。

**拆开讲**：`describe()` 的规则是"看菜下饭"——
- **数值列**（int64/float64）→ 算 count / mean / std / min / 25% / 50% / 75% / max；
- **文字列**（str）→ 算另外四个：count（个数）、unique（不重复值个数）、top（最常出现的值）、freq（它出现的次数）。

你三列全是 `str`（`dtypes` 显示 `str(3)` 就是报警信号），于是 describe 输出的是"文字摘要"：统计的全是文字列的量，电影名自然出现了，mean 自然没有。你看到的 `count/unique/top/freq` 就是文字列的标准四件套。

**修法**：数字**去掉引号**（`[50, 80, 38, 40, 60]`、`[9.7, 6.3, ...]`），文字（电影名）才加引号。以后从外部文件读到"数字被存成文字"的数据，还可以用 `df['票价'].astype(int)` 整列转换（转换函数后面特征工程课细讲）。

**顺带把第 7 问答了**（同一枚硬币的另一面）：正常情况下 describe 里**看不到电影名**，因为它是文字列、算不了 mean 等统计量，默认被跳过；你这次它出现了，恰恰是因为票价、评分"陪它一起变成了文字"。改完引号重跑，就是验收点期望的样子。

## 【本节重点总结】
1. Pandas 就是"编程版 Excel"：`Series` 是一列带标签的数据，`DataFrame` 是一张表格，两者是机器学习数据处理的起点。
2. 造表用 `pd.Series` / `pd.DataFrame`（字典写法：键 = 列名），看表用 `head`、`info`、`describe` 和属性 `shape/columns/dtypes`。
3. 记两个坑：`info()` 只打印不返回值（别套 print），`shape` 这类属性不加括号；describe 默认只统计数值列。
