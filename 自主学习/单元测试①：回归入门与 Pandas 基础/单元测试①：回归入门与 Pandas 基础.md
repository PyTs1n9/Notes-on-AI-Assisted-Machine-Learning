## 【知识速览】函数速查表

| 函数/属性 | 作用 | 记忆点 / 坑 |
|---|---|---|
| `np.array(列表)` | 列表变数组 | sklearn 吃数组不吃普通列表 |
| `arr.reshape(-1, 1)` | 一列数变 n 行 × 1 列 | `-1` = 行数自动算；sklearn 要求二维 |
| `LinearRegression()` | 创建线性回归模型 | 用之前先实例化 |
| `model.fit(X, y)` | 训练（拟合） | **只用训练集** |
| `model.predict(X_new)` | 预测 | X_new 是二维的 |
| `model.coef_` / `model.intercept_` | 斜率 w / 截距 b | 尾下划线属性，**fit 后才存在**；不加括号 |
| `train_test_split(X, y, ...)` | 随机切训练/测试集 | 返回顺序 **X_train, X_test, y_train, y_test**；永远写 `random_state` |
| `model.score(X, y)` | R² 打分 | 越接近 1 越好；看测试集分数 |
| `np.concatenate((a, b))` | 两数组首尾拼接 | 双层括号 |
| `np.random.default_rng(seed)` | 造随机数（如噪声） | 同种子 → 结果相同；和 `random_state` 是两回事 |
| `pd.Series(data, index, name)` | 造一列带标签数据 | 一维 |
| `pd.DataFrame(data, columns, index)` | 造表 | 字典写法：键 = 列名 |
| `df.head(n=5)` / `df.tail(n=5)` | 看前/后几行 | 默认 5 行 |
| `df.info()` | 表格体检报告 | **只打印不返回值，别套 print** |
| `df.describe()` | 统计摘要 | 只统计数值列（mean 等）；文字列给 count/unique/top/freq |
| `df.shape` / `df.columns` / `df.dtypes` | 行列数 / 列名 / 各列类型 | 属性**不加括号** |
| `df['列名']` | 取一列 | 单括号 → Series；双括号 `df[[...]]` → DataFrame |
| `df.loc[行, 列]` | 按**名字**取 | 名字切片**两端都包含** |
| `df.iloc[行号, 列号]` | 按**位置**取 | 从 0 数；位置切片**不含末尾**；只认数字 |
| `df[布尔条件]` | 按条件挑行 | 组合用 `&`/`|`/`~`，**每个条件各自加括号**；写 and/or 报错 |
| `pd.read_csv(路径, encoding, index_col)` | 读 CSV | 中文 `utf-8-sig`/`gbk`；`index_col=0` 配 `to_csv(index=True)` |
| `df.to_csv(路径, index, encoding)` | 存 CSV | 一般 `index=False`；`utf-8-sig` 让 Excel 不乱码 |

### 老师答疑（二.3 你的问题）

**问**："什么叫挑列、行全都要？是全选的意思吗？"

**答**：对，就是"所有行全都要"。写法：行的位置填一个**裸冒号 `:`**——冒号单独放表示"从头到尾全要"：

```python
df.loc[:, '数学']             # 所有行 + 数学列 → 一列（Series）
df.loc[:, ['数学', '英语']]    # 所有行 + 两列 → 小表（DataFrame）
df.loc['s1':'s3', '数学']     # 对照：只挑 s1~s3 的行（loc 切片两端都包含）
```

对照记：`df['数学']`（单括号取列）和 `df.loc[:, '数学']` 结果一样，后者是"行、列两段都写全"的完整写法——所以填空答案是 `df.loc[ :, '列名' ]`。
