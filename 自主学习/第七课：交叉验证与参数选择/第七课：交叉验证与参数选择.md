# 第七课：交叉验证与参数选择

## 【本节核心知识点】

一次 `train_test_split` 的分数看运气，换个 `random_state` 分数就变；**交叉验证**（cross-validation）让每份数据都轮流当测试集，用 K 次考试的平均分给出稳定成绩；**网格搜索** `GridSearchCV` 把「逐个试超参数」自动化，替你挑出最好的 `alpha`。

## 【核心概念讲解】

### 1. 先看问题：换一次划分，分数就变

第五课学过：模型的成绩要用**没见过的数据**来考。但「考哪份数据」是 `train_test_split` 随机抽的——换个 `random_state`，等于换了一套考卷，分数跟着变。本课示例 1 的实测：同一个模型、同一份数据，5 个种子的测试集 $R^2$ 从 0.9073 到 0.9432，**最高最低差 0.036**。

- 生活类比：一场随堂小测定终身——题目碰巧简单分就高，碰巧难分就低，**分不出是学生强还是运气好**。
- 分数随划分抖动 = 评估结果里掺了运气。要压掉运气，就得**多考几场取平均**。

### 2. K 折交叉验证：让每份数据都当过测试集

**K 折交叉验证**（K-fold cross-validation）：**折**（fold）= 切出来的一份数据。把数据均分成 K 份，轮流拿 1 份当测试集、其余 K−1 份当训练集，训 K 次、得 K 个分数，取平均。以 5 折为例：

| 轮次 | 测试集（当考卷） | 训练集（当练习册） | 得到 |
|---|---|---|---|
| 第 1 轮 | ① | ②③④⑤ | 分数 1 |
| 第 2 轮 | ② | ①③④⑤ | 分数 2 |
| 第 3 轮 | ③ | ①②④⑤ | 分数 3 |
| 第 4 轮 | ④ | ①②③⑤ | 分数 4 |
| 第 5 轮 | ⑤ | ①②③④ | 分数 5 |
| **最终** | — | — | **5 个分数取平均** |

- 为什么叫「**交叉**」：训练/测试的角色交叉互换——每份数据都当过测试集，也都当过训练集，谁也没被偏袒。
- 平均分比单次划分稳得多：5 场考试的平均分，比一场小测更能反映真实水平。
- 代价：要训练 K 次，**时间变 K 倍**。数据特别大时常用 K=3 省时间；常规就是 K=5 或 K=10。
- sklearn 里两个工具配合：`KFold` 定「怎么切」，`cross_val_score` 负责「训 K 次、打 K 次分、收好」。

### 3. 参数 vs 超参数：两个「旋钮」不是一个部门管的

**超参数**（hyperparameter，「超」= 在训练之前由人定的）和模型参数是两回事：

| | 模型参数 | 超参数 |
|---|---|---|
| 例子 | `coef_`、`intercept_` | Ridge 的 `alpha`、`KFold` 的 `n_splits` |
| 谁定 | `.fit()` 从数据里**学**出来 | **人**在 fit 之前手工设定 |
| 什么时候存在 | fit 之后 | 调用模型时就写好 |

- **调参**（tuning）= 调超参数。第六课纠结「alpha 取多少」就是在调参，当时是手动一个个试。
- 超参数没有「算出来」的公式解，只能**试**：每个候选值都训一遍、打个分，谁分高用谁。

### 4. 网格搜索：把「试」字自动化

**网格搜索**（grid search）：把候选值列成一张网格（比如 `alpha ∈ [0.01, 0.1, 1, 10, 100]`），**每个候选值都用交叉验证打分**，挑平均分最高的。`GridSearchCV` = 网格搜索 + 交叉验证，一个对象打包干完。

## 【核心内置函数拆解】

### ① `KFold(n_splits=5)` — 定「怎么切折」

- **作用**：指定交叉验证的切分方案（切几份、洗不洗牌），供 `cross_val_score` / `GridSearchCV` 使用。
- **完整语法**：`KFold(n_splits=5, *, shuffle=False, random_state=None)`。
- **关键参数**：
  - `n_splits`：切成几份（= K），默认 5。
  - `shuffle`：切之前要不要把数据打乱（shuffle，洗牌），默认 `False`。
  - `random_state`：打乱用的随机种子，**只在 `shuffle=True` 时生效**。
- **返回值**：一个切分器对象（splitter）；它的 `.split(X)` 会一轮轮吐出 `(训练集下标, 测试集下标)`。
- **常见坑**：默认**不洗牌**——数据本身有顺序时（比如按时间收集），前几折的测试集全是同一类，切出来的折不公平。给真实数据用时几乎总是 `KFold(n_splits=5, shuffle=True, random_state=42)`。
- **适用场景**：想自己控制切法（洗牌、固定种子让结果可复现）时。

### ② `cross_val_score(estimator, X, y, cv=5)` — 交叉验证打分

- **作用**：自动完成「切 K 折 → 训 K 次 → 打 K 次分」，返回 K 个分数，是本课的主角。
- **完整语法**：`cross_val_score(estimator, X, y, *, groups=None, scoring=None, cv=5)`。
- **关键参数**：
  - `estimator`（估计器）：要评估的模型，如 `LinearRegression()`、`Ridge(alpha=1)`。sklearn 把所有模型统称 estimator。
  - `X`、`y`：**全部数据**，不用自己先 `train_test_split`——切折的事归它管。
  - `cv`：折数（写 `5` 就是 5 折）或一个切分器对象（如 `KFold(...)`）。
  - `scoring`：打分指标。回归器（regressor，预测连续数值的模型）默认 `r2`；分类器默认 `accuracy`（准确率）。
- **返回值**：**numpy 数组**，每折一个分数，长度 = 折数。取平均用 `.mean()`。
- **常见坑**：
  1. `cv=5` 省略切分器时是**不洗牌**的 5 折——同 ① 的坑；
  2. 写 `scoring='neg_mean_squared_error'` 返回的是**负数**（sklearn 统一「分数越大越好」的口径，所以把 MSE 取了负号），真实 MSE 要再取负；
  3. 返回的是数组不是单个数，忘了 `.mean()` 打印出来会是一串。
- **适用场景**：想要一个比单次划分更稳定的模型成绩；对比多个模型时（同一套折，公平）。

### ③ `GridSearchCV(estimator, param_grid, cv=5)` — 网格搜索选超参数

- **作用**：把「每个候选超参数都交叉验证一遍，挑最高分」全流程自动化。
- **完整语法**：`GridSearchCV(estimator, param_grid, *, cv=5, refit=True)`。
- **关键参数**：
  - `estimator`：**带待调超参数的模型**，如 `Ridge()`。
  - `param_grid`（参数网格）：字典，键是超参数名，值是候选列表，如 `{'alpha': [0.01, 0.1, 1, 10, 100]}`。候选多时可以放多个键，所有组合都试。
  - `cv`：同上，用几折评估每个候选。
  - `refit`：默认 `True`——找到最优超参数后，**自动用全部数据按最优值重训一个模型**。
- **返回值**：搜索对象。`.fit(X, y)` 之后多出几个关键属性：
  - `best_params_`：最优超参数组合，如 `{'alpha': 0.1}`；
  - `best_score_`：最优组合的交叉验证平均分；
  - `best_estimator_`：refit 重训好的最优模型，可直接 `.predict()`；
  - `cv_results_`：每个候选的详细成绩（要看「每个 alpha 各得几分」就翻它）。
- **常见坑**：
  1. `best_score_` 是**交叉验证**的分，不是「留出来的测试集」的分——它是用来**选**超参数的，评估最终成绩最好另留数据（第八课综合训练会串起来）；
  2. 计算量 = 候选个数 × 折数：5 个候选 × 5 折 = 训练 25 次，网格别一口气铺太大；
  3. `cv_results_` 字段很多，取分看 `mean_test_score`，取候选看 `param_alpha` 这类 `param_超参数名` 字段。
- **适用场景**：Ridge/Lasso 的 `alpha`、KMeans 的 `n_clusters`（后面聚类部分会用到）等超参数选择。

## 【完整代码示例 + 逐行注释】

```python
# ============ 第七课：交叉验证与参数选择 ============
import numpy as np                                            # 数组工具
from sklearn.datasets import make_regression                  # 造回归数据（第六课见过）
from sklearn.linear_model import LinearRegression, Ridge      # 两个模型
from sklearn.model_selection import (                         # 本课三个新工具都从这里 import
    train_test_split, cross_val_score, KFold, GridSearchCV)

# ---------- 造数据：5 个特征，只有 3 个真正有用，2 个是噪声特征 ----------
X, y = make_regression(n_samples=120, n_features=5, n_informative=3, noise=25, random_state=42)
# n_informative=3：120 行样本、5 个特征，其中只有 3 个特征真正参与生成 y，
# 另 2 个是纯噪声特征（呼应第六课的 x3、x4）；noise=25：标签里掺随机噪声
print('X:', X.shape, ' y:', y.shape)                          # (120, 5) (120,)

# ---------- 示例1：换一次划分，分数就变 ----------
print('\n===== 示例1：换一次划分，分数就变 =====')
for seed in [0, 1, 2, 3, 4]:                                  # 5 个种子 = 5 套不同考卷
    X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.2, random_state=seed)  # 函数①（第一、二课学过）
    m = LinearRegression().fit(X_tr, y_tr)                    # 函数② 每次都重新训练（其实模型一样，划分不同）
    print(f'random_state={seed}  测试集 R2={m.score(X_te, y_te):.4f}')  # 函数③ 同模型不同考卷，分数抖动

# ---------- 示例2：cross_val_score 五折交叉验证 ----------
print('\n===== 示例2：cross_val_score 五折交叉验证 =====')
cv = KFold(n_splits=5, shuffle=True, random_state=42)         # 函数④ 定切法：5 折、洗牌、种子固定可复现
scores5 = cross_val_score(LinearRegression(), X, y, cv=cv)    # 函数⑤ 自动训 5 次、打 5 次分
print('5 折分数:', np.round(scores5, 4))                       # 返回数组，每折一个分数
print('平均分:', round(scores5.mean(), 4))                     # 最终成绩 = 5 个分数取平均

# 手动 KFold 循环对照：证明 cross_val_score 干的就是这件事
manual = []                                                   # 收集手动循环算的分数
for tr_idx, te_idx in cv.split(X):                            # 函数⑥ 每轮吐出 (训练下标, 测试下标)
    m = LinearRegression().fit(X[tr_idx], y[tr_idx])           # 用下标取行，训练
    manual.append(m.score(X[te_idx], y[te_idx]))               # 用下标取行，打分
manual = np.array(manual)                                     # 列表转 numpy 数组，好和 scores5 对比
print('手动循环:', np.round(manual, 4))
print('逐折一致:', np.allclose(manual, scores5))               # np.allclose：两个数组是否几乎相等

# 默认 cv=5 = 不洗牌的 KFold（验证坑①）
d1 = cross_val_score(LinearRegression(), X, y, cv=5)          # 不传切分器，走默认
d2 = []                                                       # 手动用"不洗牌 KFold"复现一遍
for tr_idx, te_idx in KFold(n_splits=5).split(X):
    m = LinearRegression().fit(X[tr_idx], y[tr_idx])
    d2.append(m.score(X[te_idx], y[te_idx]))
print('默认 cv=5 就是不洗牌 KFold:', np.allclose(d2, d1))       # True，默认切法就是这样

# scoring 的符号坑（验证坑②）
neg = cross_val_score(LinearRegression(), X, y, cv=cv, scoring='neg_mean_squared_error')
print('neg_mean_squared_error:', np.round(neg, 2))             # 全是负数！
print('取负号后 = MSE:', np.round(-neg, 2))                    # 取负号才还原成真正的 MSE

# ---------- 示例3：GridSearchCV 搜 alpha ----------
print('\n===== 示例3：GridSearchCV 搜 alpha =====')
gs = GridSearchCV(Ridge(), {'alpha': [0.01, 0.1, 1, 10, 100]}, cv=cv)  # 函数⑦ 5 个候选 × 5 折 = 训 25 次
gs.fit(X, y)                                                  # 函数⑧ 一次 fit 跑完整个搜索
print('best_params_:', gs.best_params_)                       # 最优超参数
print('best_score_:', round(gs.best_score_, 4))               # 最优候选的 CV 平均分
for a, s in zip(gs.cv_results_['param_alpha'], gs.cv_results_['mean_test_score']):
    print(f'alpha={a:<6} 平均 R2={s:.4f}')                     # 每个候选的成绩一览
ols_mean = cross_val_score(LinearRegression(), X, y, cv=cv).mean()
print('同样 CV 下 LinearRegression 平均 R2:', round(ols_mean, 4))  # 和最优 Ridge 对比
print('best_estimator_ 系数:', np.round(gs.best_estimator_.coef_, 4))  # refit 重训好的模型直接可用
```

### 手算对照（cross_val_score 的分不是天上掉的）

1. **每折分数哪来的**：手动 KFold 循环打出的 5 个分数和 `cross_val_score` **逐折一致（True）**——它不是什么魔法，干的就是「切折 → 训练 → 打分」的循环，只是帮你把循环写好了。
2. **平均分手算**：用打印出来的四舍五入值算 $(0.9422 + 0.9236 + 0.9466 + 0.9544 + 0.8471) \div 5 = 4.6139 \div 5 = 0.9228$ ✅ 和打印的平均分一致（四舍五入前的第 5 位小数有微小舍入差，可忽略）。
3. **alpha 表怎么读**（这节的重点不是数字本身，是读法）：
   - `alpha` = 0.01 / 0.1 / 1 三行都是 0.9228——真实差距在小数点后第 5 位（浮点级差别，无实际意义），说明这批数据接近理想线性，小惩罚之间谁也不比谁强；
   - `alpha` = 10 开始掉分（0.9149），100 直接崩到 0.6783——**惩罚过头，把有用特征也压坏了**（第六课「alpha 过大会误伤」的实锤）；
   - 最优 Ridge（0.9228）和 LinearRegression（0.9228）打平——正则化没帮上忙也没坏事。**网格搜索的价值首先在于把坏区间排掉**：你现在确定地知道「alpha 别超过 10」，而不是拍脑袋。

```py
from sklearn.datasets import make_regression
from sklearn.model_selection import cross_val_score, KFold, GridSearchCV
from sklearn.linear_model import LinearRegression, Ridge
import numpy as np

X, y = make_regression(n_samples=80, n_features=5, n_informative=2, noise=30, random_state=7)
cv = KFold(n_splits=5, shuffle=True, random_state=42)
scores_l5 = cross_val_score(LinearRegression(), X, y, cv=cv)
print(np.round(scores_l5, 4))

manual = []
for train_idx, test_idx in cv.split(X):
	m = LinearRegression().fit(X[train_idx], y[train_idx])
	manual.append(m.score(X[test_idx], y[test_idx]))
manual = np.array(manual)
print('手动循环:', np.round(manual, 4))
print('逐折一致:', np.allclose(manual, scores_l5))

scores_r5 = cross_val_score(Ridge(alpha=1), X, y, cv=cv)
print(np.round(scores_r5, 4))
print('LR 平均分:', round(scores_l5.mean(), 4))
print('Ridge 平均分:', round(scores_r5.mean(), 4))
print('结论：Ridge 平均分比 LR 高', round(scores_r5.mean() - scores_l5.mean(), 4))

gs = GridSearchCV(Ridge(), {'alpha': [0.01, 0.1, 1, 10, 100]}, cv=cv)
gs.fit(X, y)
print(gs.best_params_)
print(gs.best_score_)
for a, s in zip(gs.cv_results_['param_alpha'], gs.cv_results_['mean_test_score']):
	print(f"alpha:{a:<6} R2:{s:.4f}")

neg = cross_val_score(LinearRegression(), X, y, cv=cv, scoring='neg_mean_squared_error')
print(neg)
print('因为使用的指标器是neg_mean_squared_error，sklearn中，分数越大越好，所以返回 −MSE，取负号还原')
```

## 【本节重点总结】

1. 单次 `train_test_split` 的分数带运气成分；**K 折交叉验证**让每份数据轮流当测试集，K 个分数取平均，成绩才稳（代价：训练 K 次）。
2. `cross_val_score(模型, X, y, cv=KFold(...))` 返回每折分数的数组，手动循环能逐折复现它；`scoring='neg_*'` 的指标记得取负号。
3. **超参数**（如 `alpha`）是人定的，只能试出来：`GridSearchCV` 用网格 × 交叉验证自动试、自动挑 `best_params_`，`best_score_` 是 CV 分，最终评估要另留测试集（第八课串全流程）。
