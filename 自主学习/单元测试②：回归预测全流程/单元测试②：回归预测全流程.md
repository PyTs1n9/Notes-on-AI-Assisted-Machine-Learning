## 【知识速览】函数速查表

| 函数/属性 | 作用 | 记忆点 / 坑 |
|---|---|---|
| `mean_absolute_error(y_true, y_pred)` | MAE：平均绝对误差 | 单位跟 y 一样，最好解释 |
| `mean_squared_error(y_true, y_pred)` | MSE：平均平方误差 | 单位是 y 的**平方**，放大了大误差 |
| `root_mean_squared_error(y_true, y_pred)` | RMSE：MSE 开根 | 单位跟 y 一样 = `np.sqrt(mse)` |
| `r2_score(y_true, y_pred)` | R²：解释了多少波动 | 越接近 1 越好，**可能是负数** |
| `Ridge(alpha=1)` | L2 正则化回归 | alpha 越大系数被压得越小，但压不到 0 |
| `Lasso(alpha, max_iter=...)` | L1 正则化回归 | 能把系数压到 **0**（特征选择）；常要加大 `max_iter` 防不收敛 |
| `KFold(n_splits=5, shuffle=True, random_state=...)` | 切 5 折的方案 | 不写 `shuffle=True` 就按数据原顺序切，会切偏 |
| `cross_val_score(m, X, y, cv=cv)` | 交叉验证打分 | 返回 n 折个 R² 的数组；要跟别的分数比，**必须同一个 cv** |
| `GridSearchCV(模型, {'alpha': [...]}, cv=cv)` | 网格搜索调参 | 穷举所有候选组合 |
| `gs.fit(X, y)` | 跑搜索 | 验收值按 `fit(X, y)`（全数据）钉 |
| `gs.best_params_` / `gs.best_score_` | 最优参数 / 它的 CV 分 | `best_score_` 是**裁判分**，不能当最终成绩 |
| `gs.cv_results_['mean_test_score']` | 每个候选的平均分 | 跟 `param_alpha` 一起读，画出 alpha 曲线 |
| `model.coef_` | 系数 | 尾下划线属性，`fit` 后才有、不加括号；看 Lasso 哪个被压 0 |

## 【我的作答】

### 一、概念题（每题 2 分，共 10 分）

1. MAE是平均绝对误差，MSE是平均平方误差，RMSE是均方根误差，都是越小越好；RMSE是MSE的开方根，所以减少了放大的惩罚力度
2. 可能出现负数，R2=1的时候波动最小，R=0的时候基本没回归上，负数完全没学会
3. 规定系数生长，L2是平方和正则化，L1是绝对和正则化，分别惩罚的是alpha越大的系数和单独筛去跨度很大的系数，Lasso可以把突兀的系数删去
4. 把样本切成5份，分别把每一次切的样本当成一次测试集。Train Test Split只按照Test Split切了一次，也就是说前者训练了5次，后者只训练了一次，前者取5次训练的平均值，所以分数更高。
5. best_score_是用来评定超参数的分数，不能直接把它当成模型的最终成绩。评定最终成绩看的是线性回归、岭回归、套索回归的R2分数。这句话的意思是裁判就是best_score_，他就是用来判断超参数的考生才是测试集。

### 二、函数题（每题 2 分，共 8 分）

1.  两者的返回值是一样的，然后就返回时的单位跟y也一样。
2. α调大调小都会把系数往低推。Nice interaction. 是最大收敛数不加大的话，可能还没有收敛完就被终止了。
3. 第一个参数是指切成几折； 第二个参数是指是否洗牌，true就是是，false就是不洗； random state指的是随机种子，用于给固定的实验。如果忘记写shuffle和true的话，那么就是默认在排好序的数据里切分。
4. 返回的是一个数组。网格搜索指标里的平均测试成绩。网络搜索指标里最好的超参数。网格搜索指标最好超参数对应的分数。第一个用来判断测试成绩就是模型测试完的好坏； 第二个和第三个都是用来判断超参数大小的。

### 三、纠错题（每题 3 分，共 12 分）

1. 预测值和真实值写反了。如果是分数直接错误。r2 = r2_score(y_te, pred)
2. 首先，网格搜索。调参是用的原始数据，并不是用训练集或者测试集。其次，best_score_是超参数的评定指标，并不能写在测试成绩报告里。
3. α不是越大越好。套索中未排除数据异常很大的系数。岭回归中会压低所有的系数。
4. 前者分了5折，后者没有写分几折，默认就是1折，就没有交叉的意义了。不能直接比大小模型，得看他的实际测试分数。

import numpy as np
import pandas as pd
from sklearn.model_selection import (
    train_test_split, KFold, cross_val_score, GridSearchCV
)
from sklearn.linear_model import (
    LinearRegression, Ridge, Lasso
)
from sklearn.metrics import (
    mean_absolute_error, mean_squared_error, root_mean_squared_error, r2_score
)
df = pd.read_csv('sales.csv', encoding='utf-8-sig')
X = df[['广告投入', '优惠券', '店员人数', '会员数', '客流量']]
y = df['销量']
cv = KFold(n_splits=5, shuffle=True, random_state=7)

models = {
	"OLS": LinearRegression(),
	"Ridge": Ridge(alpha=1),
	"Lasso": Lasso(alpha=1, max_iter=10000)
}

for name, m in models.items():
	scores = cross_val_score(m, X, y, cv=cv)
	print(f"Name: {name:<6} Scores: {np.round(scores, 4)} 平均分: {round(scores.mean(), 4)}")

gs = GridSearchCV(Ridge(), {'alpha': [0.01, 0.1, 1, 10, 100]}, cv=cv)
gs.fit(X, y)
print(gs.best_params_)
print(gs.best_score_)
for a,s in zip(gs.cv_results_['param_alpha'],gs.cv_results_['mean_test_score']):
	print(f'Alpha: {a:<6} Scores: {s}')
print('0.01,0.1,1.0,10基本平坦。α等于100的时候直接掉。说明100是坏区间')

### 一、概念题（7 / 10）

**1. ⚠️ 1 / 2**：「RMSE 是 MSE 开根、MSE 放大了惩罚」方向对 ✅。但本题考的**量纲（单位）**没写出来：MAE / RMSE 的单位**跟 y 一样**（分），MSE 的单位是 **y 的平方**（分²）——所以 RMSE 好向人解释，因为报出来的数还站在「分」这个单位上。→ 回看第五课指标卡。

**2. ⚠️ 1.5 / 2**：「可能出现负数」✅，三档情况都答到了 ✅。一处措辞纠偏：R² = 1 不是「波动最小」，是模型把 y 的波动 **100% 解释完**（预测零误差）；R² = 0 = 跟「直接猜均值」一样、没有增益；R² < 0 = **比直接猜均值还差**（你说「完全没学会」，意思对）。

**3. ⚠️ 1.5 / 2**：L2 平方和、L1 绝对和 ✅，Lasso 独门绝技是把系数压成 0 ✅。两处纠偏：①「规定系数生长」应是「**防止系数疯长（过拟合）**」；② 惩罚的对象是**系数本身的大小**，不是「alpha 越大的系数」——alpha 只管**惩罚力度**：alpha 越大压得越狠。

**4. ⚠️ 1 / 2**：切法说对了（每份轮流当一次测试集）✅。但「为什么更稳」答成了「分数更高」——**答的不是本题问的**：5 折的价值是 5 次成绩取平均、**不依赖某一次运气好的切分**，分数不一定更高，是**更稳**。→ 回看第七课「5 折的意义」。

**5. ✅ 2 / 2**：best_score_ 是评超参数的裁判分、不能当最终成绩 ✅。「裁判不能兼考生」= 测试集一旦参与调参，就**既当裁判（挑参数）又当考生（报成绩）**，成绩必然虚高。

### 二、函数题（6.5 / 8）

**1. ✅ 2 / 2**：两者数值**完全相等**（RMSE 就定义成 MSE 开根），单位都跟 y 一样 ✅。

**2. ⚠️ 1 / 2**：`max_iter` 说对了 ✅（最大迭代次数，不加大会没收敛完就终止，弹 ConvergenceWarning 提示）。但 alpha 方向说混了——「调大调小都往低推」不对：**调大** → 系数被压得更小，**调小** → 放松、系数接近普通线性回归。

**3. ⚠️ 1.5 / 2**：`n_splits` 切几折、`shuffle` 是否洗牌、`random_state` 固定实验 ✅。忘写 `shuffle=True` 的后果没说到点：按原顺序切会让每折**偏科**（比如某折全是前期样本），分数失真。

**4. ✅ 2 / 2**：`cross_val_score` 返回 n 个 R² 的数组 ✅；`mean_test_score` 是每个候选的平均 CV 分（读 alpha 曲线用）、`best_params_` 最优参数、`best_score_` 它对应的分 ✅。

### 三、纠错题（7 / 12）
