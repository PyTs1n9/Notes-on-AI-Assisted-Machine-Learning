## 【知识速览】函数速查表

| 函数/属性 | 作用 | 记忆点 / 坑 |
|---|---|---|
| `mean_absolute_error(y_true, y_pred)` | MAE：平均绝对误差 | 单位跟 y 一样，最好解释 |
| `mean_squared_error(y_true, y_pred)` | MSE：平均平方误差 | 单位是 y 的**平方**，放大了大误差 |
| `root_mean_squared_error(y_true, y_pred)` | RMSE：MSE 开根 | 单位跟 y 一样 = `np.sqrt(mse)` |
| `r2_score(y_true, y_pred)` | R²：解释了多少波动 | 越接近 1 越好，**可能是负数** |
| `Ridge(alpha=1)` | L2 正则化回归 | alpha 越大系数被压得越小，但压不到 0 |
| `Lasso(alpha, max_iter=...)` | L1 正则化回归 | 能把系数压到 **0**（特征选择）；常要加大 `max_iter` 防不收敛 |
| `KFold(n_splits=5, shuffle=True, random_state=...)` | 切 5 折的方案 | 不写 `shuffle=True` 就按数据原顺序切，会切偏 |
| `cross_val_score(m, X, y, cv=cv)` | 交叉验证打分 | 返回 n 折个 R² 的数组；要跟别的分数比，**必须同一个 cv** |
| `GridSearchCV(模型, {'alpha': [...]}, cv=cv)` | 网格搜索调参 | 穷举所有候选组合 |
| `gs.fit(X, y)` | 跑搜索 | 验收值按 `fit(X, y)`（全数据）钉 |
| `gs.best_params_` / `gs.best_score_` | 最优参数 / 它的 CV 分 | `best_score_` 是**裁判分**，不能当最终成绩 |
| `gs.cv_results_['mean_test_score']` | 每个候选的平均分 | 跟 `param_alpha` 一起读，画出 alpha 曲线 |
| `model.coef_` | 系数 | 尾下划线属性，`fit` 后才有、不加括号；看 Lasso 哪个被压 0 |

## 【测试题】

### 一、概念题（每题 2 分，共 10 分）

1. MAE、MSE、RMSE 三个指标的单位（量纲）有什么区别？为什么说 RMSE 比 MSE 好向人解释？
2. R² 会出现负数吗？R² = 1、R² = 0、R² < 0 各代表什么情况？
3. 为什么需要正则化？Ridge（L2）和 Lasso（L1）惩罚的对象各是什么，Lasso 的「独门绝技」是什么？
4. 5 折交叉验证具体是怎么切数据的？为什么说它比「一次 `train_test_split`」得到的分数更稳？
5. `gs.best_score_` 能直接当模型的最终成绩拿去汇报吗？「裁判不能兼考生」这句话在说什么？

### 二、函数题（每题 2 分，共 8 分）

1. `root_mean_squared_error(y_te, pred)` 和 `np.sqrt(mean_squared_error(y_te, pred))` 的返回值是什么关系？两者返回值的单位跟 `y` 一样吗？
2. `Ridge(alpha=1)` 的 `alpha` 调大、调小分别会把 `coef_` 推向什么方向？`Lasso(alpha=0.5, max_iter=10000)` 里的 `max_iter` 是干什么用的，不加大可能遇到什么提示？
3. `KFold(n_splits=5, shuffle=True, random_state=42)` 三个参数各管什么？如果忘了写 `shuffle=True`，对一份按规律排好序的数据会出什么问题？
4. `cross_val_score(m, X, y, cv=cv)` 返回什么？`gs.cv_results_['mean_test_score']`、`gs.best_params_`、`gs.best_score_` 三者各是什么、各怎么用？

### 三、纠错题（每题 3 分，共 12 分：指出错误 + 写出正确写法/说法）

1. `r2 = r2_score(pred, y_te)` ——错在哪？后果是什么？正确写法？
2. 为了「让成绩好看」，用测试集调参：`gs.fit(X_te, y_te)`，再把 `gs.best_score_` 当测试成绩写进报告——错在哪？
3. 有人总结：「alpha 越大越好，因为惩罚越强越防过拟合」——这句话错在哪？用你见过的 alpha 曲线反驳它。
4. 同一批数据上，一张表里放着 `cross_val_score(m, X, y, cv=5)` 的均分和另一个 `KFold(shuffle=True, random_state=42)` 算的均分，直接比大小选模型——错在哪？

### 四、代码题（共 2 题，`.venv` 实跑并把真实输出贴进【我的作答】；数据文件在本测试文件夹里）

**题目 1：指标与正则化对比（30 分）**（数据 `score.csv`，150 行：学习时长、手机使用、睡眠时长、课外活动 → 考试成绩）

1. 读数据 + 体检：打印 `df.shape`、缺失值总数；
2. `X = df[['学习时长', '手机使用', '睡眠时长', '课外活动']]`、`y = df['考试成绩']`，`train_test_split(test_size=0.25, random_state=42)`，打印训练/测试形状；
3. 训练三模型：`LinearRegression()`、`Ridge(alpha=1)`、`Lasso(alpha=0.5, max_iter=10000)`；
4. 打印三模型的 `coef_`，再打印测试集 MAE / MSE / RMSE / R²（前三个保留 2 位、R² 保留 4 位）；
5. 一句话点评 Lasso 对「课外活动」的系数做了什么。

**验收点**：① `df.shape` == (150, 5)、缺失 0、训练 (112, 4)/测试 (38, 4)；② 指标表（±0.01，R² ±0.001）：OLS `5.88 / 50.02 / 7.07 / 0.6632`、Ridge `5.88 / 50.05 / 7.07 / 0.6630`、Lasso `5.92 / 51.26 / 7.16 / 0.6549`；③ 三行 `coef_` 齐全，Lasso 的「课外活动」系数被压成 **0（-0.0）**，并带点评句。

**题目 2：交叉验证与网格搜索（30 分）**（数据 `sales.csv`，120 行：广告投入、优惠券、店员人数、会员数、客流量 → 销量）

1. 读数据，`X` 用 5 个特征、`y` = 销量；
2. `KFold(n_splits=5, shuffle=True, random_state=7)`，对 `LinearRegression()`、`Ridge(alpha=1)`、`Lasso(alpha=1, max_iter=10000)` 各算 5 折 R²，打印逐折 5 个分数 + 平均分（4 位小数）；
3. `GridSearchCV(Ridge(), {'alpha': [0.01, 0.1, 1, 10, 100]}, cv=cv)` 在**全数据** `X, y` 上 `fit`，打印 `best_params_`、`best_score_` 和每个 alpha 的平均 R²；
4. 一句话读 alpha 曲线（哪段平、哪段掉、说明什么）。

**验收点**：① CV 平均分（±0.001）：OLS 0.8231、Ridge 0.8231、Lasso 0.8287，逐折分数都在；② `best_params_` == `{'alpha': 10}`、`best_score_` ≈ 0.8232（±0.001）；③ alpha 表 5 行齐全（0.01 / 0.1 / 1 / 10 / 100）；④ 曲线读法点到「0.01~10 基本平坦、100 明显变差 = 坏区间」才算读到。

**评分标准**：代码题以「真实运行输出 + 验收点达标」为准；概念题/函数题答到关键词即可；纠错题必须「指出错 + 给正确写法/说法」。复述比抄原句更受用。
