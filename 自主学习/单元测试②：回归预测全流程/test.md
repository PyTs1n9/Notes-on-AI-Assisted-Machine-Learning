# 一、概念题（每题 2 分，共 10 分）
1. MAE是平均绝对误差，MSE是平均平方误差，RMSE是均方根误差，都是越小越好；RMSE是MSE的开方根，所以减少了放大的惩罚力度
2. 可能出现负数，R2=1的时候波动最小，R=0的时候基本没回归上，负数完全没学会
3. 规定系数生长，L2是平方和正则化，L1是绝对和正则化，分别惩罚的是alpha越大的系数和单独筛去跨度很大的系数，Lasso可以把突兀的系数删去
4. 把样本切成5份，分别把每一次切的样本当成一次测试集。Train Test Split只按照Test Split切了一次，也就是说前者训练了5次，后者只训练了一次，前者取5次训练的平均值，所以分数更高。
5. best_score_是用来评定超参数的分数，不能直接把它当成模型的最终成绩。评定最终成绩看的是线性回归、岭回归、套索回归的R2分数。这句话的意思是裁判就是best_score_，他就是用来判断超参数的考生才是测试集。

# 二、函数题（每题 2 分，共 8 分）
1. 两者的返回值是一样的，然后就返回时的单位跟y也一样。
2. α调大调小都会把系数往低推。Nice interaction. 是最大收敛数不加大的话，可能还没有收敛完就被终止了。
3. 第一个参数是指切成几折； 第二个参数是指是否洗牌，true就是是，false就是不洗； random state指的是随机种子，用于给固定的实验。如果忘记写shuffle和true的话，那么就是默认在排好序的数据里切分。
4. 返回的是一个数组。网格搜索指标里的平均测试成绩。网络搜索指标里最好的超参数。网格搜索指标最好超参数对应的分数。第一个用来判断测试成绩就是模型测试完的好坏； 第二个和第三个都是用来判断超参数大小的。

# 三、纠错题（每题 3 分，共 12 分：指出错误 + 写出正确写法/说法）
1. 预测值和真实值写反了。如果是分数直接错误。r2 = r2_score(y_te, pred)
2. 首先，网格搜索。调参是用的原始数据，并不是用训练集或者测试集。其次，best_score_是超参数的评定指标，并不能写在测试成绩报告里。
3. α不是越大越好。套索中未排除数据异常很大的系数。岭回归中会压低所有的系数。
4. 前者分了5折，后者没有写分几折，默认就是1折，就没有交叉的意义了。不能直接比大小模型，得看他的实际测试分数。
