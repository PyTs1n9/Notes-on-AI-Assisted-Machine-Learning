# MAE 越大越好还是越小越好？
> 越小越好，因为MAE值越小，误差越小


# RMSE 为什么比 MAE 更容易受到大误差影响？
> MAE只是真实值到预测值的绝对值，MSE把误差平方，误差放大，RMSE把单元还原，但是被平方放大的误差仍然存在
> 所以RMSE 比 MAE 更容易受到大误差影响


# R²=1 表示什么？
**R²（决定系数）**是衡量回归模型解释数据变异能力的指标，取值范围通常在0到1之间。
计算公式：R² = 1 - (SS_res / SS_tot)  
- SS_res（残差平方和）：预测值与真实值差异的平方和
- SS_tot（总平方和）：真实值与其均值差异的平方和
R²=1表示完美拟合，因为此时SS_res = 0，即预测值与真实值完全相等（残差为零），模型解释了数据的所有变异。

# R² 接近 0 表示什么？
> R^2接近0，就是残差平方和越来越接近总平方和，模型直接预测均值。
> 所以R^2=0就是模型无法解释了数据变异

# 是否应该只看一个指标判断模型？
> 不可以，要综合MSE MAE RMSE R^2，
> 举个例子，R^2=1并不代表模型一定好，可能是过拟合导致的完美拟合，还要判断其他的指标
