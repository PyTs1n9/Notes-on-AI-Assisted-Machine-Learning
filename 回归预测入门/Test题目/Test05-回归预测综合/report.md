# 回归预测综合项目报告

## 一、项目目标

使用 BikeSharing数据集，hour.csv，根据年份、月份、小时、节假日、工作日、星期、天气状况以及温度、体感温度、湿度和风速等信息，预测某小时的共享单车需求量`cnt`。
预测结果可以辅助运营部门提前安排车辆调度，在高需求时段向热点站点补车，在低需求时段撤出冗余车辆。本次实验按 80%/20%
随机划分训练集和验证集，训练集用于拟合预处理器、模型和搜索参数，验证集只用于最终评价，避免使用验证信息指导建模。数据共有
17379 行、17 列，没有缺失值和重复行，目标 `cnt` 的平均值约为 189.46，最大值为 977，说明需求分布跨度较大，回归模型既要拟合常规波动，也要尽量减少高峰时段的误差。

## 二、数据基本分析与特征选择

原始字段 `instant` 只是记录编号，不具备业务预测意义；`casual` 和 `registered` 分别表示注册与非注册用户数量，两者之和正好等于目标
`cnt`。如果将它们作为特征，会把答案间接泄漏给模型，因此三列均被删除。日期列 `dteday` 转换为日期类型后，提取星期 `weekday`
，并生成二元特征 `is_weekend`
，用于表达工作日与周末的骑行规律。最终保留季节、年份、月份、小时、节假日、工作日、星期、天气状况、周末标记，以及温度、体感温度、湿度和风速。数据基本分析确认不存在缺失值和重复行，因此不需要进行缺失填补或重复值删除。考虑到共享单车需求具有明显的小时和星期周期，保留这些离散时间特征是有必要的。

## 三、数据编码与标准化

季节、年份、月份、小时、节假日、工作日、星期、天气状况和周末标记属于类别特征，使用 `OneHotEncoder`
转换为独热编码，并设置未知类别忽略策略，使模型遇到新类别时不会直接报错。温度、体感温度、湿度和风速属于连续特征，使用
`StandardScaler` 去均值并按标准差缩放。编码器和标准化器都只使用训练集拟合，再转换验证集和交叉验证折，防止训练信息从验证集泄漏。原始草稿先把数据整体标准化，随后又把标准化数据送入包含
`StandardScaler` 的流水线，造成重复缩放；最终代码将预处理统一放入 `Pipeline`，每种模型都从相同原始特征出发，比较更加公平。

## 四、模型训练与评价

实验比较 `LinearRegression`、`Ridge` 和 `Lasso` 三种线性模型。评价指标包括 MAE、RMSE 和 R²。MAE 表示预测值与真实值之间的平均绝对偏差，越小越好；RMSE
对较大误差更敏感，越小越好；R² 表示模型能够解释目标波动的比例，越接近 1 越好。三个基础模型的验证集结果如下：LinearRegression
的 MAE、RMSE、R² 分别为 74.105、100.446、0.681；Ridge 为 74.092、100.425、0.682；Lasso 为 76.344、103.567、0.661。结果显示 Ridge
与普通线性回归非常接近，说明当前特征下多重共线性影响不大；Lasso 的基础参数 `alpha=1.0` 正则化偏强，因此初始误差略高。

## 五、五折交叉验证与参数搜索

为了降低单次随机划分带来的偶然性，实验使用固定随机种子的五折交叉验证。LinearRegression、Ridge 和 Lasso 均完成五折评估，每折的
MAE、RMSE 和 R² 写入 `cv_results.csv`。随后对 Ridge 搜索 `alpha=[0.01, 0.1, 1, 10, 100]`，对 Lasso 搜索
`alpha=[0.01, 0.1, 1, 10]`，网格搜索使用训练集内部五折交叉验证，并以平均 MAE 最小为标准。搜索得到 Ridge 最优 `alpha=10.0`
，Lasso 最优 `alpha=0.1`。三种候选模型的五折平均 MAE 分别为：LinearRegression 75.902、Ridge 75.892、Lasso 75.760。由于 Lasso
的平均 MAE 最小，最终选择调参后的 Lasso 作为最终模型。最终模型在验证集上的 MAE 为 73.935，RMSE 为 100.374，R² 为 0.682。

## 六、图形结果与误差分析

`model_compare.png` 从 MAE、RMSE 和 R² 三个方面比较三个基础模型，直观展示它们性能接近，但 Ridge 略优于普通线性回归。
`prediction.png` 绘制真实值与最终模型预测值，点越接近对角线表示预测越准确。由于需求存在明显高峰，部分样本仍被低估，说明纯粹的线性模型对小时、天气和工作日之间的复杂交互表达能力有限。
`residual.png` 同时展示残差直方图和残差—预测值散点图，用于判断误差分布是否集中在零附近，以及误差是否随预测值增大而扩散。
`alpha_compare.png` 展示 Ridge 与 Lasso 不同正则化强度对应的五折平均
MAE，便于判断偏差与方差的平衡。若要进一步改进，可尝试随机森林、梯度提升树，或增加历史滞后需求、站点类别和天气预报误差等特征。

## 七、结论

本次实验完成了数据读取、基本分析、特征选择、类别编码、标准化、80/20 划分、三种回归模型训练、MAE/RMSE/R² 评估、五折交叉验证、Ridge
与 Lasso 参数搜索、最终模型选择、预测结果保存以及四类图形绘制。最终选择 Lasso，其验证集 MAE 为 73.935，RMSE 为 100.374，R² 为
0.682。该模型可以作为小时级需求预测的线性基线，但投入实际调度前，还应结合站点级历史需求、节假日活动、天气预报不确定性和当前库存进行修正。完整数据结果保存在
`output` 目录，图形保存在 `figures` 目录，源代码保存在 `env.py` 目录，错误分析与修改说明见 `error_note.md`。
